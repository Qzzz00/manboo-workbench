# 记忆(怎么读、怎么写)

真相源是本仓库 `docs/` 里的 Markdown;`~/.dsh`、`~/.claude` 下只有指针。规则写死在 `docs/记忆/README.md`,你对它只读。

## 读(省 token,按顺序)
1. `docs/记忆索引.md` —— 全仓库一行一文件,先扫一遍。
2. 问工作台长什么样 → `docs/记忆/工作台-布局.md`(改 UI 前必读)。
3. 问 Ben 是谁、怎么用 → `docs/记忆/用户-*.md`(按他的称呼建的那一份;只有一份就是它,通常叫 `用户-Ben.md`)。
4. 问某个项目 → `docs/记忆/项目/索引.md` 找到那一行,再读 `docs/记忆/项目/<名>.md`;要找文件看它的「关键文件与入口」。
5. 要事实与决定 → `docs/决策记录.md`(只有「已拍板」算事实,「待拍板」按未定处理)、`docs/能力清单-*.md`。
6. 要过程细节 → 索引指到的 `docs/交接-*.md`。
回答里列出你读了哪些文件。

## 写(只有三种,其它一律只读)
1. 追加「待拍板」条目到 `docs/决策记录.md`(带日期与依据)。
2. 新增文件:`docs/交接-<日期>-<事项>.md`、`docs/superpowers/research/*`、`docs/记忆/项目/<新项目>.md`。
3. 更新记忆文件族:`docs/记忆/项目/<名>.md` 的「进展/当前冲刺/下一步/关键文件/风险」(追加,带日期与依据)、`用户-*.md` 的「观察」段(追加)、`docs/记忆索引.md` 与 `项目/索引.md`(重写)。
4. 下班例程第 5 步的「并」:各家 AI 的记忆副本在 `docs/记忆/来自-<家>/`(那是**缓存**,只读、不改、不删);
   **每并完一份就立刻**在同目录的 `已并入.md` 里追加一行 `| 文件 | 指纹 | 日期 | 并到哪 |`,
   判定「纯技术、不并」的也记(否则明天还会列给你);每 5 份 commit 一次,别攒到最后 ——
   2026-09-26 攒到最后那次会话断在第 23 份,台账一行都没留下。
   `来源.md` 顶上那一块「这一家到哪了」是**工作台自动写的**,不要手改。
不删文件;不改 AGENTS.md、`docs/记忆/README.md`、本 SKILL.md;凭据/账号/密钥/cookie 不进任何文件。
每次写 = 一次 git commit(`chore(记忆): …`);这个仓库配了远端才 push(没配远端就只提交、不推)。
下班例程那一笔的提交与推**由工作台的代码做**,你只管你自己写的那一笔。
