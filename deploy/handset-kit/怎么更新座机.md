# 座机(树莓派话筒)更新 · 0.4.90

**这版改了什么**:座机进房前先问工作台「现在该进哪个房」,不再拿着没过期的旧房票一直撞旧房(换房 / 新一通电话后它进错房的毛病)。别的没动。

## 准备
1. 派通电,连一个**能上网的 2.4G Wi-Fi**(iPhone 热点就行;只有局域网不通外网的 Wi-Fi 会在装依赖那步卡住,看着像没反应)。
2. 要知道派的 IP(热点里一般是 `172.20.10.x`;在手机热点的「已连接设备」里看,或者问维护者)。
3. 登录派的凭据找维护者要:密钥文件(放到你 Mac 的 `~/.ssh/remarkable_paper_pro`)或派用户 `ben` 的密码。**这个包里没有任何密码或密钥。**

## 更新(在 Mac 上,终端里)
```bash
cd 座机更新包-0.4.90
bash 更新座机.sh <派的IP>
```
会问一次密码(有密钥文件就不问),然后依次:探一眼派 → 推代码 → 装依赖(第一次要几分钟,Zero 2W 上更久,**别当死机**)→ 自检(逐样报「有 / 没有」)→ 重启服务 → 打最后 20 行日志。

## 更新完怎么验
拿起话筒按一下,工作台那边应该看到座机进房;打一通电话能通就是好了。不通就把终端里「自检」那几行截图发给维护者。

## 不做的事
不碰派的系统设置、不 sudo、不重启派、不改 ALSA。
