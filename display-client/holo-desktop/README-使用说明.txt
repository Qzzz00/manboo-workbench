Aiboo 全息屏 · Windows 演示版 使用说明
========================================

【怎么用】★推荐★
1. 把整个文件夹拷到演示 Windows 电脑（holo.exe / 启动全息屏.bat / server.txt / web，放一起别拆开）。
2. 双击【启动全息屏.bat】（不是 holo.exe）。
   —— 用 .bat 启动：万一出错，黑窗会停住显示报错，不会一闪而过。
3. 会弹出黑色命令行窗口（别关，关了就停），然后自动用 Edge 全屏打开角色。
4. 退出：按 Alt+F4，或直接关掉那个黑色窗口。

【如果黑窗一闪而过 / 打不开】
- 一定改用【启动全息屏.bat】启动（别直接双击 holo.exe），窗口会停住显示原因。
- 把黑窗里的文字截图发给开发即可定位。
- 被 SmartScreen 拦：出现蓝色提示时点“更多信息 → 仍要运行”。
- 被公司杀毒/管控软件拦：把 holo.exe 加白名单，或换台没装管控的机器。

【前提】
- 这台 Windows 要能上网（连阿里云后端 your-aiboo-host:3456，聊天/DJ 才能用）。
- Windows 10/11 自带 Edge 浏览器。

【换后端地址】
- 打开 server.txt，改成你要的后端地址，保存，重新启动即可（不用重新打包）。
- 恢复默认：删掉 server.txt 或清空内容。

【端口】
- 本地 127.0.0.1:47190，纯本机，不需要局域网、不占别的设备。
