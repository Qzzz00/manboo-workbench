## 任务机制图

`task-mechanism.svg` 为本仓库的机制说明：任务上下文 → 事务官 → 执行引擎 → 已接入的 AI → 结果与证据 → 把关与记录。它表示各环节关系，不是网络拓扑，也不保证每个来源具有相同执行能力。正文解释对应机制，图中保留“投递成功不等于任务完成”。

图采用既有黑底、白字与灰线；不使用设备小图标或人物场景。源 SVG 可编辑，无脚本和外部资源。依据是 `deckRun.ts`、`topicRun.ts`、`featureRun.ts`、`engine/`、`jobLog.ts` 与 `rules.ts`，完整路径及哈希见 `sources.json`。

`scene-call.webp`、`scene-dock.webp`、`scene-inside.webp` 原样复制自 `feat/site@09e06a25b97429a0c099bc8449b89f19b1872e3c:site/media/`。2026-10-09 已在在线官网 `#demo` 核对：当前轮播确实使用这三张，分别展示通话、底座与工作台、内部结构。README 放在“人可以离开屏幕，协作继续”中的“听筒、手机与底座”区，承接多端分工，逐张配说明，不添加工作日故事。

## 磨合与进化图

`evolution-loop.svg` 说明用户的日常选择与纠正如何形成有证据的候选，进入下一次同类任务试用，再按各类判据保留或撤回，持续积累与校正。依据 `docs/设计-事务官从她的行为里学-2026-10-09.md` 与 `behaviorLog.ts`、`habits.ts`，随 0.4.109 更新为“行为与习惯已实现 · 风格与界面开发中”。行为记录、决策习惯与查询 / 撤销接口已落地，风格学习与统一管理界面仍在开发。现有实现及验证范围在 README 正文说明。

图沿用黑底、白字与灰线，采用纵向流程，已检查 640px 原尺寸与 375px 渲染。无脚本与外部资源；来源状态和哈希见 `sources.json`。

## 维护

- 新增图须解释一项功能、状态或机制；设备外观可复用官网现用素材。
- 图片使用标准 Markdown 引用，不依赖 HTML 标签居中或限宽；部分预览器会将原始 HTML 显示为文字。
- 先核对源码与实际引用，再检查正常阅读尺寸。不能仅凭文件存在或图片加载成功判断其适用性。
- 修改后核对引用、来源与哈希，检查桌面和窄屏显示；图中信息在正文中也应可读。
- 早先为官网式叙事复制的其余照片与场景图已从此目录移除；历史版本仍可从 Git 获取。
