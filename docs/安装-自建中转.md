# 安装:自建中转(出门也能用)

**这一份还没写**(卡 L4:档二文档与部署脚本整理)。在那之前:

- 不架服务器、只在家里用:看 [安装-零服务器](安装-零服务器.md)。
- 想先自己试:中转是仓库里的 `relay/`,部署脚本 `deploy/aliyun-relay-setup.sh`(中转)与 `deploy/aliyun-livekit-setup.sh`(云上的房间),
  两份都要在 ssh 那一行给域名(`RELAY_DOMAIN=…`、`LIVEKIT_DOMAIN=…`),头注释写了步骤。电脑端把中转地址写进
  `~/.dsh/workbench/model.json` 的 `relay_url`;要查更新,把你那台的清单地址写进 `~/.dsh/workbench/endpoints.json` 的 `update_manifest_url`。
  每条连接能怎么改,见 [对外连接清单](开源-对外连接清单-2026-10-21.md)。
