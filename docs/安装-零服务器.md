# 安装:零服务器(一台 Mac + 一部安卓手机 + 自己的钥匙)

日期:2026-10-21。读者:拿到开源仓库、想在自己家里用起来的人。另一档(自己架一台中转、出门也能用)见 [安装-自建中转](安装-自建中转.md)。

**先说结论**:开源构建**不带任何服务器地址**。不用注册我们的账号,也不用架服务器:在家里,手机、听筒和这台 Mac 在同一个 Wi-Fi 下,
打电话、派活、看早报都照常。出了门用不了。模型、语音、搜索用的是你自己去各家申请的钥匙,调用时会把相关内容发给那一家,**不是完全离线**。

## 一、要准备什么

| 东西 | 必须吗 | 用来干什么 |
|---|---|---|
| 一台 Mac(Apple Silicon) | 必须 | 工作台、事务官、通话都在它上面跑 |
| 一部安卓手机 | 建议 | 看材料、接电话、当座机的屏;和 Mac 连同一个 Wi-Fi |
| 实体听筒(树莓派 + 听筒) | 可选 | 提起来就能说话,见 `phone-bridge/README.md` |
| DeepSeek 的 API Key | 必须 | 事务官说话、整理、判断 |
| 火山引擎语音(识别):App ID + Access Token | 打电话要 | 电话里听懂你说的话:填在设置里走流式识别(快);只在事务官后端配了火山的话走分段识别 |
| 合成语音:火山 / 百炼 / MiniMax 任一家 | 打电话要 | 事务官开口说话 |
| 博查搜索的 Key | 可选 | 资讯里「现搜」那一步;不填就只有早报底稿 |

## 二、装

1. 按 README「安装与开发」把上游 `deepseek-harness` 和插件构建好。
2. 要安装包就在仓库根上跑 `bash deploy/build-installer.sh`。开头会打一行 **「中转:不带 · 更新清单:不带(没有构建档 = 开源缺省)」**,
   说明打出来的就是零服务器这一档。出来的 `dist/工作台安装器-<版本>.dmg` 双击、打开里面的「安装工作台.app」照提示走。
   安装时会从 `nodejs.org`、`npmmirror` 这几个公开镜像下 Node 与依赖(带 sha256 校验),只在安装与修复这一步。
3. 第一次打开:**注册一个本机账号**。账号只在这台电脑上,不会传到任何地方;登录台底下那一行会写「这台没接中转」。

## 三、填钥匙

| 在哪填 | 填什么 |
|---|---|
| 设置 › 各家的登录与密钥 › DeepSeek | DeepSeek 的 API Key |
| 设置 › 各家的登录与密钥 › 火山识别 · App ID / Access Token | 火山语音识别那一对,两格都填才算有 |
| 设置 › 各家的登录与密钥 › 博查搜索 | 博查的 Key(可选) |
| 设置 › 形象与音色 › 打开配置(事务官后端的管理页) | 合成语音那一家的 Key |

「设置 › 模型服务」里只有「用我自己的 DeepSeek 账号」一项;「用工作台提供的服务」那一项要中转,这一档不出现。
钥匙都存在这台 Mac 上(`~/.dsh/workbench/credentials.json` 等,权限 0600),界面上只显示「配了没有」,不回显。

## 四、配对手机与听筒

- **手机**:电脑上「设置 › 手机与设备 › 生成二维码」,手机 App 扫一下。手机和 Mac 要在同一个 Wi-Fi。
  手机 App 上登录账号那一步用不上(这一档没有账号可登),扫码配对就够了。
- **听筒**:听筒的服务文件里不带任何中转地址,只找这台 Mac 的 8791。经手机蓝牙配网那条路今天还要中转(卡 M5 改成交本机令牌),
  在那之前用局域网配对:电脑上生成配对码,`phone-bridge/deploy.sh <派的地址> --pair <六位码>`(见 `phone-bridge/README.md`)。
- 这台 Mac 上「允许手机在局域网访问」要开着(配对页上那个开关);系统防火墙第一次会问要不要允许传入连接,点允许。

## 五、能做什么、不能做什么

| | 零服务器这一档 |
|---|---|
| 在家打电话(手机接、听筒接) | 能。房间在这台 Mac 上 |
| 派活给本机装着的 AI、收回结果 | 能 |
| 早报、资讯 | 能;「现搜」要填博查的 Key |
| 会议录音转写 | 能(走事务官后端里配的识别) |
| 出门在外接电话、手机远程接续 | **不能**。手机出了家里的 Wi-Fi 就连不上这台 Mac(设置里那一节会说「这台没接中转」) |
| 账号换电脑登录、「我的设备」 | **不能**。账号只在这台电脑上 |
| 工作室(几台电脑一起协作) | **不能**。工作室要一台中转 |
| 自动查更新 | **不查**。「设置 › 更新」说这台不自动查;新版本到项目主页下载。自己有更新地址的,写进 `~/.dsh/workbench/endpoints.json` 的 `update_manifest_url` |
| 断了外网 | 进房、响铃、接起、字幕还在;听懂与开口要靠识别、合成那两家,断外网就没有声音 |

## 六、它还会连哪里

本机之外,这一档只连你填了钥匙的那几家(DeepSeek、火山、百炼 / MiniMax、博查),以及几个不要钥匙的公开接口。
有两条默认是开着的,不想连就关:

- **今晨快报**:默认取 Aiboo 云(`your-aiboo-host:3456`)。不想连就在 `~/.dsh/workbench/endpoints.json` 写 `"aiboo_url": "off"`。
- **AIHOT 日报**(早报底稿):默认 `aihot.news`。不想连就写 `"aihot_url": "off"`。

全表见 [对外连接清单](开源-对外连接清单-2026-10-21.md)。
