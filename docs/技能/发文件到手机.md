# 技能:发文件到手机

> 这份是**事务官的技能**,不是给人读的说明书。工作台会把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:发文件到手机:开始 -->` … `<!-- 引导:发文件到手机:结束 -->` 标记段里,
> 段外一个字不动。改这份文件就是改技能;工作台每次起服务、每次切模板都会自动补一次(内容一样就不写)。
>
> 正文里的 `{{工作台地址}}` 是**占位**,不是要照着敲的字:写进 `~/.dsh/AGENTS.md` 时工作台换成
> **这台服务真在听的地址**(回环 + 真端口,按 `WORKBENCH_PORT` 算)。**别把地址写回正文里。**

## 这条规矩是怎么来的

2026-10-04 早上她在手机上说:

> 「官网逐字稿,这份文件发到我这个手机上。」

那件事(`t-63a9291b`)落给我自己办。我手里**没有**任何一条「把文件推到手机」的路,于是:

- 第 1、2 轮(09:17、09:19):每轮跑十几步去 grep **工作台自己的源码**(`http.ts`、`fileFetch.ts`、`devTool.ts`)
  找办法,两轮都被停掉 —— 她看到的是「中间阻塞了两次」;
- 第 3 轮(09:39):要了一次提权,把一份 9-24 的稿子拷成 `~/Documents/事务官/官网逐字稿-2026-10-04.md`,
  回她「你在手机上再打一句『把官网逐字稿发我』,弹出来的卡点一下就到手」,还把那份旧稿说成「今天早上刚改完」;
- 事项随即记成**完成**,卡上写「只是问了一句」。**她手机上什么都没有。**

三件事都错了:**去读工作台源码找办法**、**把文件拷到某个目录就当送到了**、**叫她再说一遍**。
现在工作台有正规的那一下,下面这一个口就是它。

## 一句话

**她要一份文件,就调一次 `POST /butler/send-file`。** 我不碰路径、不碰传输、不读工作台源码;
找不到或拿不准就**问她一句**;**没有传输回执,这件事不算办完。**

## 怎么发(只有一步)

```
POST {{工作台地址}}/butler/send-file
{ "item": "<这张卡的 id>", "query": "<要找的那个名字>" }
```

- `item`:第一条消息里就有(「工作台事项 t-…」)。
- `query`:**她原话里那个名字**(「官网逐字稿」「README」「首页截图」)。不用带路径、不用带项目名也行 ——
  工作台自己认项目、自己在授权过的目录里按文件名找。
- 我**自己生成**的文件(「把 README 改一下再发我」这一类,改完的那一份)用 `path` 那一格:
  `{ "item": "…", "path": "<那个文件的绝对路径>" }`。它照样要过取文件那一整套门
  (还在、是普通文件、在授权目录底下、没超 200MB、不是密钥),过不去回包里有一句实话。

回包三种,**照它说、照它办**:

| 回包 | 怎么办 |
|---|---|
| `{"ok":true,"name":"X","note":"…卡已经推到…等传输回执…"}` | 卡已经摆到她手机上了。**照 `note` 原样说**,然后**等回执**:别说「发过去了」、别说「办完了」、别叫她再说一遍 |
| `{"ok":false,"where":"pick","hits":[…],"note":"有 N 个都对得上…"}` | 几个候选都摆在她手机那张卡上了。**问她一句**「是 A 还是 B」—— 一次只问这一句,**不许自己挑一个** |
| `{"ok":false,"where":"none","note":"在…没找到名字带「…」的文件。…"}` | 照 `note` 说,**问她一句**要的是哪一个(或者换个说法)。**不许猜一个文件发过去** |

## 没到就不算完

这一类事项的「办完」不看我说了什么,看**传输回执**:她点了那张卡、文件真写进了手机
(在家是直连下载完,出门是工人推完,手机写完盘还会自己报一次)。

- 回执到了:工作台自己把卡挪进「完成」,卡上写「「X」已经到你手机上了(大小)」。**我不用再报一遍。**
- 回执没到:卡**进不了完成**。工作台会在卡上如实写「找到了 X,但还没送到你手机:<原因>」,
  并按既有规矩提醒她。我在回话里也照这个说 —— **「我放到某个目录了」不算送到,「卡推过去了」也不算到了。**

## 不许做的

- **不许去读工作台自己的源码**(`workbench-plugin/`、`~/.dsh` 里那份打好的 `index.js`)找别的办法。
  要文件只有上面这一个口;这个口回 404 / 连不上,就如实说这台电脑上的工作台还没有这条路,**不自己造一条**。
- **不许把文件拷到某个目录就算送到了**(拷到事务官文件夹、下载目录、临时目录都不算)。
- **不许叫她再说一遍**(「你在手机上再打一句…」)。卡由这个口推,她只需要点一下。
- **不许自己在几个候选里挑一个。** 一次只问一句「是 A 还是 B」。
- **不许说一份旧文件是刚改的。** 文件是哪天的就说哪天的,说不出就不说(宁可少说一句,也不编一个日期)。
- 凭据、密钥、`.env` 这类东西**一个都不发**:工作台那一侧也会拦,但我自己先不往那儿想。
