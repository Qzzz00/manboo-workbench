## 这条规矩是怎么来的

维护者 2026-09-26 16:41 在电话里说:

> 「给那个 Claude,现在正在做统筹交接的那个会话窗口,发个信息问一下:现在进行到什么情况,
> 大概什么时候能处理完。」

我当时答的是:「那条统筹交接是客户端里跑着的会话,不挂在看板事项上,这边捎不进话去。**它归哪件事**?」

他把这算作一个 bug:**「它不能给你发信息」**。

他是对的。那句「它归哪件事」是**把我自己的限制推给他** —— 他看见的是一扇开着的窗口、里面有个 AI 在干活,
他要往里说一句话;「先归到某件事项上」是我这边的账本要求,不是他的事。

## 一句话

**他点名的任何一条会话都能捎话,不问它挂不挂在事项上。** 认不准就把候选念给他选,不猜;捎到了说捎到了,
捎不到说清是哪一步没成。

## 怎么捎(只有一步)

```
POST {{工作台地址}}/sessions/relay
{ "who": "<他点名那一句的原话>", "text": "<他要捎的那句话,原话>" }
```

- `who`:**他怎么说就怎么填** —— 「正在做统筹交接的那个 Claude 会话」「Codex 刚才那条」「停着在等我的那条」。
  工作台按 `/state.sessions` 里的**标题、哪一家、什么状态**去认(念了会话编号也认)。
- `text`:**他的原话,一个字不改**。不要替他改写成需求、不要替他补一句「请汇报进度」——
  他要那条会话回答的是他问的那一句,我加的每一句都会被那家当成要求的一部分。
- 回包三种:

| 回包 | 怎么说 |
|---|---|
| `{"ok":true,"note":"捎到了 —— 你那句话已经送进 Claude 那条会话里了。"}` | **照 `note` 原样说**。不用再报别的 |
| `{"ok":false,"where":"pick","note":"有 2 条都对得上:1. …;2. …。问他是哪一条。","candidates":[…]}` | **照 `note` 念给他听**,问他是哪一条;他说了再调一次(`who` 填他说的那一句,或者带上 `candidates` 里那条的 `agent` + `session_id`)。**不许自己挑一条送** |
| `{"ok":false,"where":"none","note":"没认出他说的是哪一条会话(这会儿有 5 条)…"}` | 照 `note` 说,问他是哪一条。想先看看有哪几条:`GET {{工作台地址}}/state` 的 `sessions`(标题 · 哪一家 · 状态),念几条给他听 |
| `{"ok":false,"where":"desk","note":"捎不进去:…"}` | **照 `note` 原样说**(哪一步没成)。三种:那家的窗口没开 / 那条会话不在了 / 送话那只手对这家不通。电脑上可以点「去回答」把那段对话调到前面,他自己说那一句 |

他已经指明了是哪一条(上一轮念过候选、或者他自己念了编号)时也可以直接带上那两个字段:

```
POST {{工作台地址}}/sessions/relay
{ "agent": "claude", "session_id": "<那条会话的 id>", "text": "<他的原话>" }
```

## 回话怎么收回来

送进去那句话前面工作台加了一个记号(`【事务官捎话 xxxxxx】`,同派活那套)—— 那条会话回的话就接在它后面。

- 他问「它回了吗」「它怎么说」:看那条会话此刻的样子 ——
  `GET {{工作台地址}}/state` 里那一条的 `activity`(「最近在做什么 · 3 分钟前」)与 `status`;
  要看最近几轮就 `GET {{工作台地址}}/sessions/digest?agent=<哪家>&id=<会话 id>`。**照读到的说**。
- 它回的话里如果是在**问他**,工作台自己会把那一问摆到「等你」那一堆里(卡 T 那条路),我不用再报一遍。
- **读不到就说读不到**,别替那条会话编一句回答(D13)。

## 不许做的

- **不要问他「这归哪件事」**,也不要为了捎一句话去建一张卡 —— 捎话不需要事项(2026-09-26 那通电话)。
- **不猜是哪一条**。认出几条就念给他选;一条都对不上就问他。送错窗口比捎不到糟得多。
- **不改写他的话**。要捎的内容只能是**他自己说的那句**。
- **不假装送到了**。回包说捎不进去就照原话说捎不进去(D13)。
- 要给**已经在办的某件事**补一句话,那是另一条路(那条事项底下的会话,`POST {{工作台地址}}/butler/item/say`);
  要**新派一件活**给别家,走「派活给别家Agent」那一节。这一条只做一件事:把他的话送进一条**已经开着**的会话。
