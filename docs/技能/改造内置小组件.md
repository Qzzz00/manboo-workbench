# 技能:改造内置小组件

> 这份是**事务官的技能**。工作台会把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:改造内置小组件:开始 -->` … `<!-- 引导:改造内置小组件:结束 -->` 标记段里,
> 段外一个字不动。**两种模板下都写** —— 「我想把这一格改成……」跟她做产品还是做运营无关。
> 依据:`docs/设计-用户自己的那一层-2026-09-23.md`(本体只有一个,我们发版;用户层在她机器上,原地不动)。

## 什么时候用这一条

她说的是「**工作台上现成那一格**我想改成……」。三个内置格都算:

| 她说的 | 哪一格 |
|---|---|
| 「数据复盘我想去掉平均观看时长」「那几个数我只想看曝光和涨粉,字大一点」 | **数据复盘**(`review`) |
| 「发布计划我想看成一个列表,不要日历」「只给我看这周要发的」 | **发布计划**(`publish`) |
| 「素材管理我想只留脚本和封面两个按钮」「加一行最近改过的文件」 | **素材管理**(`files`) |

判据:她要的是**那一格长什么样 / 显示哪几个数**。
「把数据复盘挪到右边」是布局(走《用说话改布局》);「这个月数据怎么样」是复盘(走《运营-复盘》)。

## 先看:这一格是不是已经在她的用户层里(2026-10-21 起)

随手记、素材管理、选题池、发布计划、数据复盘、消耗数据这几格,大多数机器上已经是**用户层里的小组件**
(`/state.user_layer.widgets` 里 `status: "ok"`、`replaces` 是那一格)。是的话**不另做一格**,直接改她那一格:

1. 复述一遍她要什么(照她的原话);
2. 她说「就这样」→ `POST /user-layer/fix { "said": "<她的原话>" }`。工作台把活派给能写代码的那一家,
   **工作区只开到用户层目录**,交代里写着先读目录里的 `契约.md`、本体一个文件都不改;
3. 回执里 `dispatch_ok` 是 false 就把 `dispatch_note` / `error` 原样念给她;
4. 改完那一格下一拍自己换上,不用重启。改坏了那一格自动用上一版,原因在 设置 →「这台电脑」→「用户层」。

不在 `user_layer` 里的那一格,才走下面这条。

## 我怎么做:给她做一格**她自己的版本**,内置那格收起来

**不找源码、不改安装包、不写补丁。** 内置那三格是**本体**,本体只有一个、我们发版热更新;
在她机器上改它的下一次更新就被盖掉,而且会把她那台改坏。
用户层里能有的是**她自己那一格**(`~/.dsh/workbench/用户层/网页小组件/<id>/`),于是:

1. **复述**一遍她要什么(照她的原话,不润色);
2. 走《开发一个小工具》那条路,**预填**一条造模块的需求 —— 交代里写清**这一格从 `/state` 的哪几个字段读数**;
3. 她点「就这样」,工作台把它**派给这台电脑上能写代码的那一家**(我不自己写网页;
   一家都派不出去时工作台会如实说「这台电脑上没有能写代码的 Agent」,我把那句话原样念给她);
4. 新那一格出现在窗位叠最右边 → **我复述一遍它做了什么,请她看一眼**;
5. **她说行**,我才用一句话把内置那一格收起来(《用说话改布局》那条路);
6. 不满意 → 「撤销」把内置那格放回来;那一格也能移进回收站(**不删**)。

**顺序不能换**:先有她自己那一版、她看过说行,才收内置那一格。
反过来做的话,中间那段时间她两格都没有。

## 第 2 步:交代里写清从哪儿读数

小组件只能打那九条接口(`GET /state` 是读什么都走的那一条)。
**所以交代里必须点名字段** —— 写不清字段,那一家就会去编一个数(D13 最常犯的地方)。

### 数据复盘 → `/state.xhs`

```
GET /state → state.xhs
  login: { connected, nickname? }        登录态(nickname 读不到就缺席,别编一个名字)
  accounts[]: { index, name, uid?, connected, ranges[], trends? }   一个账号一份
  ranges[]:   { range, date, at, metrics[] }                        合计那一行(近 7 日 / 近 30 日)
  metrics[]:  { key, label, kind, value?, raw?, derived?, why?, prev? }
  trends?[]:  折线图(**只有真取到的那一天才有点**,缺的天整条不出现)
  fetches[]:  { at, ok, got, total, trigger, reason? }  自取记录
  last_ok_at?  refresh_ready_at?  note?  total_note?
```

三条必须写进交代的实话:

- **显示 `raw`,不要自己格式化**:`raw` 是后台页面上原样那串(「1.1万」「11.1%」「00:11」);
- **`value` / `raw` 缺席 = 后台这次没给**。那一格**空着**,把 `why` 原样贴在下面(比如平均观看时长那一项,
  平台首页根本没有);**不补 0、不估算、不拿上一周期顶上**;
- **`derived` 有值 = 这个数是算出来的**(「合计」「按曝光加权」),界面上要让她看出来这不是后台写着的字。

「刷新」那颗键打 `POST /xhs/refresh`(白名单第八条)。**受它原有的闸**:两次之间至少 10 分钟,
没到就原样回上一次的结果 —— 交代里要写明**别写重试循环**,下一次能点的时刻在 `refresh_ready_at`。

### 发布计划 → `/state.tasks.tasks`

```
GET /state → state.tasks.tasks[]
  planned_at?   计划哪天发(选题)——摆位置先看它
  due?          普通事项那个日期;planned_at 没有就退回它
  published_at? 实际发布日。有它 = 已发布
  title / status / topic? / project_id?
state.now      今天是哪天**由它给**
```

两条:

- **未发布 / 已发布是两个视图**:没有 `published_at` 的按 `planned_at`(退回 `due`)摆,
  有 `published_at` 的按它摆。一条卡只出现在一个视图里;
- **不读浏览器的时钟**:今天是哪天用 `state.now`(服务端那一刻的 ISO),
  按**本地时区**切天(`toISOString().slice(0,10)` 在东八区每天 00:00–08:00 给的是昨天)。
  读不出 `now` 就**一天都不标逾期** —— 宁可不说,不猜。

要新建一条就打 `POST /task/create`;挪一条打 `POST /task/move`。

### 素材管理 → `/state.template`

```
GET /state → state.template
  asset_dirs?  { "<文件夹名>": "<绝对路径>" }   素材那几个固定子文件夹
  asset_files? { "<显示名>": "<绝对路径>" }     素材那一行里的文件(收藏网址)
```

- **两块都可能整块缺席**:做产品模板下没有「素材」这回事,运营模板下没配工作目录时也没有真路径。
  缺席就**那一行整条不画**,不摆一排点不开的按钮;
- 点开一个文件夹打 `POST /files/asset-reveal { "name": "脚本" }`(白名单第九条)——
  **只收文件夹名**,名字就是 `asset_dirs` 里的键,路径由工作台自己解析。
  任意路径的 `/files/reveal` **打不通**,交代里别写它;
- **贴 Finder 真窗那件事做不到**:内置那一格里的 Finder 窗是本体用壳摆上去的(`/files/rect`、`/slot/*`
  不在那九条里)。她要的是那个的话,**照实说做不到**,问她「换成一排能点开的文件夹按钮行不行」。

## 第 5 步:收起内置那一格(她点头之后)

走《用说话改布局》同一条路,**不自己拼布局 JSON**:

```
POST /butler/item { text: "把数据复盘收起来", orientation: "landscape" | "portrait" }
```

工作台会摆一张确认卡,**她点「就这样」才真收**。收起**不是删掉**:她说「把数据复盘显示出来」就回来,
说「撤销」也回来。所以我在第 5 步只说一句:「你那一版我看着是 X,行的话我把内置那格收起来」。

## 输入

1. 她那句原话(**不改写**);
2. 哪一格(认不准就问一句:「你说的是右边那个日历,还是左边那一排?」);
3. 她要的那一格里**显示哪几个数 / 哪几个按钮**(第 2 步要照它点字段)。

## 不做的

- **不找工作台源码、不改安装包、不打补丁、不碰 `~/.dsh`。** 本体只有一个,我们发版更新它;
  在她机器上改它 = 下一次更新就盖掉 + 她那台可能起不来。
- **不自己写那个网页。** 写代码的活派给能写代码的那一家(设计 C2:事务官自己不干活);
  派不出去就如实说,**不自己顶上**。
- **不替她点「就这样」。** 造模块那一下、收起那一下,两道门都是人做的。
- **不先收内置那一格。** 顺序是「她自己那一版做好 → 她看过说行 → 再收」。
- **不编数。** `/state` 里缺席的字段在她那一格上就空着,把 `why` 原样贴出来。
- **不许引外网**(CDN、字体、图床):那块 iframe 的 CSP 会拦,引了也加载不出来。
- **不在页面里放任何 API Key、密码、Cookie**;页面里也没有执行命令的接口。
- **做不到的说做不到**:贴真 Finder 窗、读别的后台(那要先建采集器,走《做一个看数据的小组件》)、
  改内置那一格自己 —— 这三样都如实说,不拿一个像样的替代品冒充她要的东西。
