# 技能:用说话改布局

> 这份是**事务官的技能**。工作台会把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:用说话改布局:开始 -->` … `<!-- 引导:用说话改布局:结束 -->` 标记段里,
> 段外一个字不动。**两种模板下都写** —— 排布局这件事跟他做产品还是做运营无关。

## 什么时候用这一条

他看着界面说了一句**关于版面**的话:

- 「把消耗数据挪到项目区下面」
- 「把随手记藏起来」
- 「项目区改叫账号」
- 「底部那排高一点」
- 「撤销」(刚改完之后)

判据是**他说的是这块屏幕自己**,不是屏幕上的内容。「把爆款拆解那件事做了」是一件事项,
不是一次布局改动 —— 里面有个「把」字不算数。

## 写请求要带身份头(2026-09-28,A11)

底下这几条 POST(`/butler/item`、`/layout/*`)都属于「改工作台上显示的状态」——
**只有他本人、我、和工作台自己按证据算**改得动。所以每一条写请求都带上:

```
-H "x-workbench-actor: $WORKBENCH_BUTLER_ACTOR"
```

那个值在我自己的环境变量里(开机现生、重启即换、不落盘)。没带会回 403,那句话里会再说一遍怎么带 ——
补上重发一次就行。详见「派活给别家Agent」那一段开头。

## 我不自己动手改

工作台已经有一条现成的路,**我走它,不自己拼 JSON 打 `/layout`**:

1. `POST /butler/item { text: "<他的原话>", orientation: "portrait" | "landscape" }`
2. 工作台自己用词表认这句话。认出来了,它回 `{ ok: true, layout_ask: {...} }`,
   并在他的界面上摆一张确认卡(「我把 X 挪到 Y,对吗?」/「就这样」/「不动」)。
   **这一刻布局一格没动。**
3. 他点了「就这样」,工作台自己走 `POST /layout/confirm`,改完回一句
   「挪好了,不合适说『撤销』。」
4. 他说「撤销」,同一条 `/butler/item` 会直接回退上一步。

所以我在这条链路上要做的只有一件事:**把他那句话原样转过去,并带上他此刻看的是哪一版布局**。

## 输入

1. 他那句原话(**不改写**、不润色、不"帮他说得更清楚");
2. `orientation`:横屏还是竖屏。不知道就读 `GET /state.layout` —— 有 `landscape` 分支
   且他刚才谈的是「右侧栏 / 底部那一排」时是横屏。**拿不准就问一句**,不要猜:
   同一句话在两个方向上是两件不同的事(竖屏根本没有"右侧栏")。

## 步骤

1. 判断这句话说的是不是版面。不是 → 走别的技能,这一条到此为止。
2. 是 → `POST /butler/item`,原话 + orientation。
3. 回包里有 `layout_ask` → **只说一句**「我摆了一张卡在你输入框上面,对的话点『就这样』」。
   **不要替他点**(那张卡是这条链路上唯一一道人做的门)。
4. 回包里是 400 + 一句人话(比如「这句里有『别』,我怕理解反了」)→ **把那句话原样念给他**,
   请他换一种说法。**不要自己改一版再试一次** —— 那等于替他决定了他想要什么。
5. 他说「撤销」→ 同样 `POST /butler/item { text: "撤销" }`,不需要确认。

## 我做得到哪些

工作台的词表认得这七种改动,**别的一律做不到**:

| 他说 | 会发生什么 |
|---|---|
| 「往上/往下/往左/往右挪」 | 那一格挪一格 |
| 「挪到项目区下面」「放到右侧栏」 | 横屏:挪进右侧栏(项目区钉在最上,所以就在它下面) |
| 「挪回底部那排」 | 横屏:回底部那一排 |
| 「藏起来」「收起来」 | 收起(不是删掉) |
| 「显示出来」「放出来」 | 再显示 |
| 「改叫 X」 | 换那一格的标题(最多 10 个字) |
| 「高一点/矮一点/宽一点/窄一点」 | 调那一格(或底部那一排)的占比 |
| 「把 A 和 B 换个位置」 | 两格对调 |

## 不做的

- **不自己拼布局 JSON 打 `/layout`。** 那条路会把整份布局覆盖掉,一个字段填错就是他排了
  半天的版面没了。`/butler/item` 那条路每次只改他说的那一格,而且改之前自动存了快照。
- **不替他点「就这样」。** 门是人做的。
- **不改写他的原话。** 词表认的是他说的字,我一润色就可能认成另一件事。
- **不猜方向。** 不知道横屏竖屏就问。
- **模块删不掉。** 他说「把 X 删了」时告诉他只能藏起来(以后还能再显示),问一句是不是这个意思。
- **一次一格。** 他说「把所有模块都藏起来」时不做,请他一格一格说。
- **不碰 `/slot/*`、`/dock/*`、`/files/rect`。** 那是工作台自己摆原生窗用的,动了会把
  贴好的窗弄乱(这条与自定义模块那份产出规范里的禁令是同一条)。
