# 技能:初稿 → 定稿(协作写作)

> 这份是**事务官的技能**。工作台会在**自媒体运营模板**下把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:运营-初稿定稿:开始 -->` … `<!-- 引导:运营-初稿定稿:结束 -->` 标记段里,
> 段外一个字不动。做产品模板下**不写**。

## 什么时候用这一条

`选题/<名>/框架.md` 已经有了,他说「开始写」「我把细节填一下」「你帮我润一遍」。

**框架还没有就先走 `运营-想法梳理与内容框架`。** 没有框架直接写稿,写出来的是我的东西,不是他的。

## 这一条的铁律:**顺序不能反**

> 创作者填细节 → 我完善 → 创作者把关。

他的经历、他的情绪、他的数据,只有他有。我先写一版让他改,他会顺着我的句子改,
稿子就变成「AI 写的 + 他改了几个词」—— 那正是他说要避免的东西。

所以:**我不先写正文。**

## 输入

1. `选题/<名>/框架.md`(结构、角度、给谁看);
2. 他按框架填的细节(口述或打字都行);
3. `账号/<名>/账号.md` 的风格;
4. 第二轮起:上一版 `初稿.md` 与他的修改意见。

## 步骤

### ① 按框架取细节(一段一段来)

照框架的段落顺序,一段问一次:

> 「第 2 段『我当时怎么判断的』—— 你当时具体看到什么、心里怎么想的?随便说,我记着。」

他说什么我记什么,**逐字记**。一段没说清就追问一句,**不要替他补**。
他说「这段你看着写」时,答:「这段没有你的东西就没意思了 —— 给我一件具体的事就行,一句话也够。」

### ② 我来完善(只做四件事)

1. 顺句子:口语转成能读的书面口语,**保留他的用词习惯**;
2. 补结构:段落衔接、小标题、序号;
3. 收开头结尾:开头 3 秒的钩子、结尾的引导动作,各给 2 个备选;
4. 标出**我拿不准的地方**:凡是我不确定是否属实、是否他本意的,行尾打 `〔待你确认:…〕`。

**不加他没说过的事实、数字、案例。** 需要一个数据就打 `〔缺:…〕`,不要填一个像样的数字进去。

### ③ 他把关

把初稿念/给他看,明确问三件事:

- 哪里不是你的话?
- 哪里少了你想说的情绪?
- `〔待你确认〕` 那几处怎么定?

他改完 → 更新 `定稿.md`,并在文件里记这一轮改了什么。

### ④ 每一轮都要看得见

`定稿.md` 末尾有 `## 改动记录`,一轮一条:**谁改的、改了哪几段、为什么**。
`初稿.md` **不覆盖**:第二版初稿追加成 `## 第 2 版` 一节,旧版留着。
改了什么要能一眼看出来 —— 他要能随时说「还是第一版那句好」。

## 固定产物

`<工作目录>/选题/<选题名>/初稿.md`:

```markdown
# <选题名> · 初稿

> 由事务官生成于 <YYYY-MM-DD>,依据:框架.md + 他 <YYYY-MM-DD> 口述的细节。
> 顺序:他填细节 → 我完善 → 他把关。这一版的正文骨架来自他的原话。

## 第 1 版(<YYYY-MM-DD>)

### 他填的细节(原话,未改写)
- 第 1 段:<原话>
- 第 2 段:<原话>

### 我完善后的正文
<正文,行尾带 〔待你确认:…〕 / 〔缺:…〕 标记>

### 开头备选
1. <…>
2. <…>

### 结尾备选
1. <…>
2. <…>
```

`<工作目录>/选题/<选题名>/定稿.md`:

```markdown
# <选题名> · 定稿

> 由事务官生成于 <YYYY-MM-DD>,依据:初稿.md 第 <n> 版 + 他 <YYYY-MM-DD> 的把关意见。
> **这一份是他拍过板的。** 我不再自行改动;要改先问。

## 正文
<正文>

## 改动记录(倒序)
- <YYYY-MM-DD> 他:把第 3 段换成现场那段对话(原因:更具体)
- <YYYY-MM-DD> 我:顺句子、补小标题,未增事实(依据:初稿 ② 步)
```

定稿落盘之后,提一句:「要不要我查一遍词?」(→ `运营-合规查词`)、
「要不要出标题和封面?」(→ `运营-发布包装`)。

## 不做的

- **不先写正文**。顺序反了这条技能就白做了。
- **不编事实与数字**。缺什么打 `〔缺:…〕`。
- **不删他的原话**。「他填的细节」那一节只增不改。
- **不在定稿上偷偷改字**。定稿是他拍过板的,改之前先问。
- **不替他发布**。我不碰任何平台的发布按钮。
