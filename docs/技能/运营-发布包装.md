# 技能:标题、短文案、标签、封面建议

> 这份是**事务官的技能**。工作台会在**自媒体运营模板**下把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:运营-发布包装:开始 -->` … `<!-- 引导:运营-发布包装:结束 -->` 标记段里,
> 段外一个字不动。做产品模板下**不写**。

## 什么时候用这一条

`选题/<名>/定稿.md` 有了,他说「起个标题」「文案怎么写」「加什么标签」「封面写什么」,
或者定稿落盘后我问的那一句他答了「要」。

四件事(标题 / 短文案 / 标签 / 封面)**一次做完、落同一个文件** —— 它们要互相呼应,
分四次做出来的东西会各说各的。

## 输入

1. `选题/<名>/定稿.md` 全文;
2. `账号/<名>/账号.md`:定位、风格、人群、平台(**平台决定字数与标签形态**);
3. 有的话:`账号/<名>/笔记/` 里过去几条的标题(看他惯用的句式,**不要模仿爆款句式**);
4. 有的话:数据复盘里的封面点击率 —— 用来说明「上一批封面表现如何」,取不到就不提。

## 步骤

1. **先用一句话说清这条内容卖的是什么**(信息 / 情绪 / 方法 / 判断)—— 四样东西都围着它转;
2. **三组备选**,每组是**一整套**:标题 + 短文案 + 标签 + 封面,**同一个方向**。
   三组之间要真的不同方向(例如:① 痛点直给 ② 反常识 ③ 场景代入),
   **不要三个同义改写** —— 那等于只给了一个选择;
3. 每组后面写一行 **「它赌的是什么」**:这组在赌哪类人点进来、赌他哪一秒停下;
4. **标题**:按平台给长度提示(小红书标题上限 20 字左右,超了会被截 —— 超过就标出来),
   不用「震惊」「必看」这类词;
5. **短文案**:开头一句要能独立成立(信息流里常只露第一行);结尾一句引导互动,
   **不要「不转不是…」这类道德绑架**;
6. **标签**:3~6 个,分两类写清 —— 「大词(有流量、竞争大)」与「精准词(人少、对味)」,
   每个标签后面注一句为什么;**不编平台热榜数据**;
7. **封面**:见下面那一节;
8. **查一遍词**(→ `运营-合规查词`),命中的当场换掉再给他;
9. 念三组给他听,让他选一组或者混搭,**不要替他选**。

## 封面建议(与标题呼应是这一节的全部重点)

每一组的封面写三样:

- **封面文字**:一行主字(≤ 9 字)+ 可选一行副字(≤ 14 字)。
  **主字不能是标题的复制**,也不能跟标题说两件事 —— 它要么是标题那句话的**结论**,
  要么是标题那句话的**缺口**(标题提问 → 封面给半个答案;标题下结论 → 封面给场景)。
  写完自检一句:「把标题和封面并排放,是不是一句完整的话?」不是就重写。
- **画面**:拍什么 / 用哪一段素材 / 人在不在画面里 / 视线朝哪;
- **可读性**:主字放哪(左上 / 居中 / 下三分之一)、会不会被平台 UI 压住、
  手机上缩到列表那么小还认不认得出。

封面文字同样要过一遍查词。

## 不做的

- **不编平台数据**。没有热榜、没有搜索量、没有「这个标签有 X 万浏览」—— 我拿不到这些。
- **不给三个同义改写**冒充三组备选。
- **不用极限词**(见 `docs/技能/违禁词表.md` 第一、二节),不用道德绑架式引导。
- **不替他选**,也不把某一组说成「推荐」之外的「最好的」。
- **不碰发布**。我不登录平台、不点发布。
