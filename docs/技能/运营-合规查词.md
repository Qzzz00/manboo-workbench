# 技能:合规查词

> 这份是**事务官的技能**。工作台会在**自媒体运营模板**下把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:运营-合规查词:开始 -->` … `<!-- 引导:运营-合规查词:结束 -->` 标记段里,
> 段外一个字不动。做产品模板下**不写**。

## 什么时候用这一条

- 他说「查一下词」「这段能发吗」「有没有违禁词」;
- **每次 `定稿.md` 落盘之后、`发布包装.md` 给出三组之后,我自己主动过一遍**
  (过完只说结果,一个字没命中就一句「查过了,没有命中」);
- 他把脚本/标题/短文案/封面文字直接粘过来。

## 输入

1. 要查的文本:**脚本 / 标题 / 短文案 / 标签 / 封面文字**,四样都要查,一样都不能漏;
2. `docs/技能/违禁词表.md` —— **唯一的判据**。这份表在仓库里,读它,不要凭记忆举例。

## 步骤

1. **先说清查了什么**:「查了定稿正文、三组标题、三组短文案、三组封面主字。」
   没拿到的那一样要点名:「封面文字你还没定,这一样没查。」
2. **逐词扫**,命中就记下:**命中的词 / 它在哪一句 / 出自词表第几节**;
3. **按节分档报**,措辞不能混:
   - **第一节(法条原文)** → 「这是《广告法》第 X 条点了名的,**要改**。」
   - **第二节(常见词库,非权威)** → 「这是常见词库里的词,**非权威**,不同地方口径不一样,
     建议换一个说法。」 ——**不许说成「违法」**;
   - **第三节(平台类别)** → 「这一段落在『<类别>』里,平台规则可能管,你自己再看一眼。」
     ——**不做逐词判定**;
4. **每个命中给 1~2 个替换建议**,替换后的句子要**保住他原来的意思**,
   换完把整句念出来让他对;
5. **一个都没命中就直说**「没有命中」,不要为了显得有用去挑刺;
6. 有选题上下文时写文件(见下);没有上下文(他随手粘一段)就只在会话里说,**不落文件**。

## 固定产物

有选题时:`<工作目录>/选题/<选题名>/查词.md`

```markdown
# <选题名> · 查词

> 由事务官生成于 <YYYY-MM-DD>,依据:docs/技能/违禁词表.md(第一节法条 / 第二节非权威词库 /
> 第三节平台类别)。查的是:定稿正文、标题、短文案、标签、封面文字。

- **查了**:<四样里真的拿到的那几样>
- **没查**:<没拿到的那几样 + 为什么>
- **命中**:<N> 处

## 命中
| # | 命中的词 | 出现在 | 出自 | 档位 | 建议换成 |
|---|---|---|---|---|---|
| 1 | 最 | 标题第 1 组「<原句>」 | 词表 §一 | 法条原文,要改 | <改后的整句> |
| 2 | 第一 | 短文案「<原句>」 | 词表 §二 | 常见词库,非权威 | <改后的整句> |

## 落在平台类别里的段落
- 「<原句>」→ <类别>(词表 §三):<提醒一句>
```

一处都没命中时,文件只写前面那几行 + 一句「没有命中」。

## 不做的

- **不联网、不登录**。零氪查词那类插件要频繁登录,这一条存在的理由就是不那样做。
- **不凭记忆举词**。判据只有 `docs/技能/违禁词表.md`;表里没有的词就不是命中。
- **不把第二、三节说成法条**。措辞按第 3 步那三档,一个字都不要越档。
- **不替他改稿**。给替换建议,改不改、改成哪个,他定。
- **不下「这条能发 / 不能发」的结论**。我只报命中与出处。
