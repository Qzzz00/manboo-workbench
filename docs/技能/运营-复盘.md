# 技能:单篇复盘 / 深度复盘

> 这份是**事务官的技能**。工作台会在**自媒体运营模板**下把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:运营-复盘:开始 -->` … `<!-- 引导:运营-复盘:结束 -->` 标记段里,
> 段外一个字不动。做产品模板下**不写**。

## 两种复盘,别混

| | 单篇复盘 | 深度复盘 |
|---|---|---|
| 什么时候 | 一条发出去几天后 | 他想弄清「为什么别人比我好」 |
| 额外输入 | 无 | **他给的几条对标笔记链接**(我去采) |
| 产物 | `选题/<名>/复盘.md` 的「单篇」一节 | 同一个文件的「深度」一节 |

两种都**先让他自评,再由我总结**。顺序反过来的话,他会顺着我的结论点头,
而他脑子里那条真正的原因就再也说不出来了。

## 输入

0. **先读两样**(2026-09-22,「越用越懂你」那条线的起点):
   - `账号/<名>/账号.md` 里「风格与偏好(工作台学到的)」那一段 —— 工作台的下班例程
     从她的 `经验.md` 与各选题的 `审核记录.jsonl` 拼的,**里面每一句都是她自己说过的话
     或数出来的次数**;
   - `账号/<名>/经验.md` —— 她历次复盘认下来的那几句。
   读它们是为了**不再让她重复交代一遍**:上一次复盘得出「封面放人脸比放锅好」,
   这一次就不该再当成新发现说一遍。**但它们不是证据**:这一次的结论仍然要挂在
   这一次的数或这一次的原文上。两样都不存在就跳过,不要因为没有它们就不办事。
1. 这条内容的 `选题/<名>/定稿.md` 与 `发布包装.md`(标题、封面、标签是什么);
2. **数据快照**:数据复盘那一格里的近 7 日 / 近 30 日八个指标与折线图那三条线。
   - **只用取到的那几项**。某一项后台没给就说没给,**不补 0、不估算**;
   - 折线图上**缺的那几天是真的没取到**,不要说成「那几天没数据 = 表现差」;
3. 深度复盘还要:**他给的对标笔记链接**(2026-09-22 起改成这样,上一版是让他粘文本)。
   - 一条链接一次 `POST /collect/note {url}`,采回来的两份在
     `<工作目录>/采集/<日期-笔记标题>/`:`笔记.md`(标题、短文案、标签、作者、发布时间、源图文或视频)
     与 `评论.md`(≤100 条高赞,**不含子评论**);
   - **我只从他给的那一条链接进**:不搜关键词、不翻博主主页、不要「帮我找几篇同类的」。
     他要我找,我就照实说这一句 —— 那是采集与爬虫的分界线;
   - 采集失败(未登录 / 风控页 / 验证码 / 这条打不开)**就停在那里如实说**,不重试、不换个法子。
     那时候可以退回上一版的做法:请他把正文粘给我。

## 步骤 · 单篇复盘

1. **先把数摆出来**,一句话一个数,只念取到的:
   「曝光 <raw>、观看 <raw>、封面点击率 <raw>、涨粉 <raw>;点赞和收藏后台这次没给。」
   有上一周期就带一句「对 <日期> 那一份:↑/↓ <百分比>」,**没有就不说涨跌**。
2. **让他先打分再说话**,三个问题,一次问一个:
   - 这条你自己打几分(1-5)?
   - 你觉得最好的是哪一部分?
   - 如果重做一次,你会改哪里?
2.5 **他答完当场把自评落盘**(2026-09-22)。在此之前自评只活在这条对话里,
   聊完就散了 —— 下一次复盘、下一次写定稿,谁都读不到它。
   一次 `POST /topic/<选题名>/review`,正文五格:

   ```json
   {
     "score": 4,
     "good": "<他说的「最好的是哪一部分」,原话>",
     "bad": "<他说的「会改哪里」,原话>",
     "next": "<下次怎么做,一个动作>",
     "lesson": "<经验一句话>",
     "account": "<这条选题归哪个账号>"
   }
   ```

   三条分寸:
   - **原话那三格一个字都不要替他润色**。他说「结尾太仓促」就写「结尾太仓促」;
   - `lesson`(经验一句话)会**同时**追加进 `账号/<名>/经验.md` —— 所以它只写
     **下一条内容能直接用上**的那一句,不是这一条的总结;写不出来就**整格不给**;
   - `account` 不知道就**不填**(工作台会如实回一句「经验那一句没落」),
     **不猜一个账号** —— 猜错的话这句经验会去影响另一个账号的画像。
3. **他答完我才开口**。我说的每一句都要么挂着一个数,要么挂着定稿/封面里的一句原文:
   - 封面点击率低 + 曝光正常 → 问题大概率在封面与标题这一对(把当时那对原文念出来);
   - 点击率正常 + 平均观看时长短 → 前 3 秒与开头那一段;
   - 观看正常 + 涨粉少 → 结尾没有给关注的理由;
   - **取不到的指标不参与判断**,并且明说「这一项没取到,所以 X 这件事我判断不了」。
4. **提炼 1~3 条可复用的经验**,每条必须写清**依据**(哪个数 / 哪句原文);
5. **给下一条的一个动作**(只给一个,能马上做的);
6. 写文件。

## 步骤 · 深度复盘

1. **先要链接**,一次说清要什么:
   > 「把你想对标的 3~5 篇笔记的链接发我就行 —— 在小红书里打开那条笔记,把地址栏那一条复制过来。
   > 我用你自己那个浏览器窗口打开它,把标题、文案、标签和前 100 条高赞评论采下来;
   > 我**只从你给的链接进**,不会去搜、也不会去翻谁的主页,更不会点赞或关注。」
   他给几条就用几条,**给不满 3 条也照做**,在产物里写清「只对了 N 条」。
   - 一条一条采(工作台一次只处理一条,同一条 10 分钟内不重采,每天有上限);
   - **哪一条采失败就在产物里点名写出来是哪一条、为什么**,不要把它悄悄略过;
   - 他直接粘了文本过来,照样收 —— 采集只是省他的力气,不是必须走的路。
2. **逐篇拆**,每篇只记看得见的:开头第一句、结构几段、标题句式、标签、
   他提供的互动数(**他没给的数我不写**);
3. **对照他自己那篇**,列差距,一条差距一条证据(两边的原文并排);
4. **让他先说**:「你觉得这几篇比你好在哪?」—— 同样是他先说;
5. **我再总结**:哪几条差距是**可学的**(句式、结构、选题角度),
   哪几条是**学不了的**(账号体量、时间点、他没有的素材)—— 学不了的要点名说清,
   不然他会去追一个追不上的东西;
6. **给 1~2 条下一轮要试的**,每条写清「怎么验证它起没起作用」;
7. 写进同一个 `复盘.md` 的「深度」一节。

## 顺手能做的一件:爆款拆解

对标的那条是**视频笔记**时,可以接着 `POST /collect/breakdown {url}` 拆一次:
本机转写(whisper.cpp,音频不出这台电脑)+ 抽帧 → 出一份 `拆解.md`,
里面**每一段都带时间戳**(开头 / 正文结构 / 结尾 / 钩子 / 节奏)。

念它的时候必须带上这一句:**那份逐字稿是机器转的,可能有出入**,
时间戳就是给他回去核对原片用的。**不要把转写稿当成原话引用**。

## 固定产物

`<工作目录>/选题/<选题名>/复盘.md`。

**「自评」那几节不是我写的** —— 它由上面第 2.5 步那条路由写,格式钉死,我不手改它:

```markdown
## 自评(<YYYY-MM-DD>)
- **自评分**:<n>/5
- **好在哪**:<他的原话>
- **差在哪**:<他的原话>
- **下次怎么做**:<一个动作>
- **经验一句话**:<下一条能直接用上的那一句>
- **谁填的**:<他在工作台上填的 / 事务官代填>
```

他没填的格**整行不出现**(不写「未填」);同一份自评写两遍只有一节;
改天再复盘一次就多一节,旧的一节一个字不动。

我写的是下面这两节:

```markdown
# <选题名> · 复盘

> 由事务官生成于 <YYYY-MM-DD>,依据:<日期> 的数据快照(近 7 日)+ 他的自评 + 定稿/发布包装原文。
> 快照里没取到的指标在下面标着「没取到」,一个数都没有补。

## 单篇(<YYYY-MM-DD>)
- **数据**:曝光 <raw> / 观看 <raw> / 封面点击率 <raw> / 平均观看时长 <raw> /
  点赞 <raw> / 收藏 <raw> / 涨粉 <raw>(没取到的写「没取到」)
- **对上一周期**:<↑/↓ 百分比 + 对哪一天那一份>;没有就写「没有上一周期可比」
- **他的自评**:<n>/5;最好的是 <…>;要改的是 <…>
- **我看到的**:
  - <结论>(依据:<数 / 原文>)
- **可复用**:
  - <一条>(依据:<…>)
- **下一条就做这一件**:<一个动作>

## 深度(<YYYY-MM-DD>)
- **对标了几条**:<N> 条(他 <日期> 给的链接,采集于 <时间>;或:他粘过来的文本)
- **采集里没拿到的**:<哪一条、为什么>(全都拿到就写「都拿到了」)
- **逐篇**:
  - 《<标题>》:开头「<第一句>」;结构 <n> 段;标签 <…>;互动 <他给的数 / 他没给>
- **他觉得好在哪**:<他的原话>
- **差距(可学的)**:
  - <差距>(证据:对方「<原文>」/ 我们「<原文>」)
- **差距(学不了的,别追)**:
  - <差距>(为什么学不了)
- **下一轮试这 1~2 条**:
  - <做法> —— 怎么算有效:<可验证的口径>
```

## 不做的

- **只从他给的链接进**。不搜关键词、不翻博主主页、不做「这个赛道的爆款都给我来一批」。
  他要我去找,照实说:那是爬,我不做。
- **不点任何东西**。采集这条路上只有「打开那一页 + 往下滚」两个动作,
  不点赞、不收藏、不关注、不评论。遇到验证码就停下告诉他,**不替他过**。
- **不替他登录**。采集用的是他自己那个浏览器窗口里的登录态,我一个凭据都不取。
- **不编数**。后台没给的指标不估算;他没给的互动数不猜。
- **不先下结论**。他自评之前我只念数,不做评价。
- **不说「照这个趋势会…」**。三个点连成的线不预测未来。
- **不拿行业均值比较** —— 我手上没有那种数据。
- **不手改「自评」那几节**。那是他自己打的分与原话,改它等于替他改口供;
  他说填错了,就让他重新填一次(会多一节,带新日期,旧的留着)。
- **不替他往 `经验.md` 里塞话**。那一份只收他在复盘里认下来的那一句 ——
  它会被回写进账号画像、我下一次先读它;塞一句我自己的结论进去,
  等于把我的判断伪装成他的偏好,而且越用越像真的。
