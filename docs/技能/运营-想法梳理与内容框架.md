# 技能:想法梳理 → 内容框架

> 这份是**事务官的技能**。工作台会在**自媒体运营模板**下把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:运营-想法梳理与内容框架:开始 -->` … `<!-- 引导:运营-想法梳理与内容框架:结束 -->`
> 标记段里,段外一个字不动。做产品模板下**不写**。

## 什么时候用这一条

他抛来一个**还没成形的想法**:「我想做一期讲 X 的」「今天遇到个事,能不能拍」
「有人问我 Y,是不是能做成内容」。

已经有框架、直接让我写稿的,走 `运营-初稿定稿`;只是让我记一句的,那是随手记,不要升级成选题。

## 输入

1. 他这一段原话(**原样留着**,后面要写进产物的「原始想法」一节,不许改写);
2. `账号/<名>/账号.md` 的定位 / 风格 / 人群 / 平台;
3. 有的话:`账号/<名>/目标.md`(这一轮想发什么方向)。

## 步骤

**一次只问一个问题,等他答完再问下一个。** 一口气抛五个问题,他会只答最后一个。
要不要问、问哪一件,照《需求确认点》那一段办(不复述、拿不准才问、嘴里只说一条)。

1. **不复述,直接接着往下聊**:他刚说完,他知道自己说了什么。他的原话原样留进「原始想法」一节,用他的词;
2. **沿三条线延伸**,每条线至少问到一句能写进框架的话:
   - **可行性**:这事你自己经历过吗 / 手上有画面和数据吗 / 需要采访或实拍吗 / 大概多久能出;
   - **实用性**:看的人拿走什么 —— 一个方法、一个判断、还是一个情绪出口?给谁看的最合适?
   - **趣味性**:这里面最反常识 / 最有冲突 / 最让人想接着看的是哪一句?开头 3 秒说什么?
3. **给 2~3 个切入角度**,每个角度一句话 + 一句「它赌的是什么」,让他挑一个。
   他都不满意就回到第 2 步再延伸一轮,**不要自己挑一个往下走**;
4. **定形式**:图文还是视频、大概几分钟 / 几张图 —— 按账号的既有形式先给一个默认,他能改;
5. **搭框架**:开头 / 正文分段 / 结尾 / 一句钩子,每段写**要讲什么**,不写台词
   (台词是 `运营-初稿定稿` 那一条的事);
6. **定选题名**:用一个能当文件夹名的短词(不带 `/`、`\`、`..`,不以点开头,不超过 30 字),
   **由他拍板**,我只给建议;
7. 写产物,念一遍,问「按这个往下写?」

## 固定产物

`<工作目录>/选题/<选题名>/框架.md`:

```markdown
# <选题名> · 内容框架

> 由事务官生成于 <YYYY-MM-DD>,依据:他 <YYYY-MM-DD> 口述的想法 + 账号.md 的定位/人群/风格。

- **账号**:<账号名>
- **形式**:图文 / 视频(<时长或图数>)
- **一句话**:<这条内容说的是什么>
- **给谁看**:<人群,取自账号.md 或他当场说的>
- **他们拿走什么**:<一句话>

## 原始想法(他的原话,未改写)
> <原话>

## 延伸出来的三条
- **可行性**:<结论 + 依据>
- **实用性**:<结论 + 依据>
- **趣味性**:<结论 + 依据>

## 选定的角度
<一句话> —— 备选的另外两个:<…>、<…>(他选的是第 <n> 个)

## 结构
1. 开头(钩子):<要讲什么>
2. <段落名>:<要讲什么>
3. <段落名>:<要讲什么>
4. 结尾:<要讲什么 + 引导动作>

## 待确认
- <还没问出答案的那几件事,一条一行;没有就写「无」>
```

选题文件夹是 `<工作目录>/选题/<选题名>/`,同一个选题后面几条技能的产物都落在这里。

## 不做的

- **不替他决定选题**。角度给备选,拍板是他的。
- **不改写他的原话**。「原始想法」那一节逐字照抄,连口语都留着 —— 它是后面所有判断的依据。
- **不去搜资料、不去抓竞品**。这一条只做梳理;要资料是 `运营-素材准备清单` 那一条,
  要对标笔记是他自己粘过来的(见 `运营-复盘`)。
- **不写台词**。框架里出现整句口播稿,就是越过了他填细节那一步。
