# 技能:收藏网址

> 这份是**事务官的技能**。工作台会在**自媒体运营模板**下把它整段写进 `~/.dsh/AGENTS.md` 的
> `<!-- 引导:运营-收藏网址:开始 -->` … `<!-- 引导:运营-收藏网址:结束 -->` 标记段里,
> 段外一个字不动。做产品模板下**不写**。

## 什么时候用这一条

他说「把这个链接收藏一下」「这个网站记一下」「存到收藏里」,或者直接甩来一条链接
并说了一句「留着」。

**只是提到一个网址、没让我存的,不要存。** 素材管理那一格里的「收藏网址」是他的东西,
不是我的剪贴板。

## 输入

1. 链接本身(他粘的原样那一串);
2. 他顺口说的那句话 —— 它就是备注;
3. 已有的 `<工作目录>/素材/收藏网址.md`。

## 步骤

1. **原样收下链接**,不改大小写、不去掉参数、不展开短链(展开要联网,我不做);
2. **标题**:他说了就用他说的;他没说就问一句「这个存成什么名字?」
   —— **不要打开链接去取网页标题**(那是联网抓取)。他不想起名就用域名当标题,
   并在备注里写「标题是域名,他没起名」;
3. **备注**:他那句话原样写进去;他什么都没说就留空,**不要替他编一句用途**;
4. **查重**:同一个链接已经在文件里了 → 不重复写,回一句
   「这个已经在收藏里了(<已有标题>),要改备注吗?」;
5. **追加一行**到文件末尾(**只追加,不重排、不删别的行**);
6. 回一句「存好了,在素材管理 →「收藏网址」里」。

## 固定产物

`<工作目录>/素材/收藏网址.md`,**一行一条**,格式钉死:

```markdown
- [标题](链接) —— 备注
```

备注可以没有,那就只写 `- [标题](链接)`。文件长这样:

```markdown
# 收藏网址

> 一行一条:`- [标题](链接) —— 备注`。你可以直接在这里改。
> 工作台的素材管理那一格里点「收藏网址」就能找到这个文件。

- [小红书创作者中心](https://creator.xiaohongshu.com/) —— 后台数据在这儿
```

文件不存在时**先按上面那个头建出来再追加**(头两行 + 空行 + 条目)。

## 不做的

- **不打开链接**。不抓网页标题、不预览、不判断这是个什么网站。
- **不重排、不去重整份文件**。只追加一行;同链接已有时只提醒,不动旧行。
- **不存他没让我存的东西**。
- **不存带凭据的链接**。链接里出现 `token=` / `password=` / `key=` 这类参数时,
  **停下来问一句**:「这条链接里带着像是凭据的参数,要我原样存吗?」他说存才存。
