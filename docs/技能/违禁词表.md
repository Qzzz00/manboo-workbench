# 违禁词表(查词技能用的那一份)

> **这份表分三节,三节的可信度不一样,查词时要按节报出处。**
> 第一节有法条原文可对;第二节是网上流传的「极限词库」,**非权威**;第三节是平台口径,
> **没有任何平台公开过逐词清单**,所以那一节写的是类别,不是词。
> 技能 `docs/技能/运营-合规查词.md` 读的就是这一份。改词表就是改技能的判据 ——
> 加词的时候必须同时写清它是哪一节的。

## 一、法条里点了名的(有出处,可以说死)

出处:《中华人民共和国广告法》(2021 修正)。下面每条后面括号里是条款号。

- **「国家级」「最高级」「最佳」** —— 法条第九条第(三)项原文列举的三个词,以及
  **「等用语」**三个字所覆盖的同类绝对化表述。
  → 这一条是**法条原文**,命中即必改。
- **「治愈」「疗效」「转好」「康复」「安全」「无毒副作用」** 这类**医疗用语与承诺疗效**的说法,
  用在**非药品、非医疗器械**的东西上(第十七条:除医疗、药品、医疗器械广告外,不得涉及
  疾病治疗功能,不得使用医疗用语或者易与药品、医疗器械混淆的用语)。
- **保健食品**不得**宣称疾病预防、治疗功能**(第十八条)。
- **药品、医疗器械、保健食品**不得用**代言人/患者/专家**作推荐证明(第十六、十八条)。
- **烟草**不得在大众传播媒介发布广告(第二十二条)。
- **教育培训**不得对升学、通过考试、取得学位学历或者合格证书,或者对教育、培训的效果
  **作出明示或者暗示的保证性承诺**(第二十四条)。
- **投资理财**不得对未来效果、收益**作保证性承诺**,不得明示或暗示**保本、无风险、保收益**
  (第二十五条)。

## 二、常见词库(**非权威**,来源是公开流传的「广告法极限词清单」)

> ★ **这一节不是法条,也不是任何机关公布的表。** 它是网上广为流传的商家自查清单,
> 大致对应「第九条那个『等用语』到底包括什么」的民间理解,各地市场监管的实际口径并不一致。
> 查词命中这一节时,措辞只能是**「这是常见词库里的词,非权威,建议换一个说法」**,
> 不许说成「违法」。

### 2.1 绝对化 / 排他

第一、全网第一、排名第一、销量第一、NO.1、TOP1、独家、唯一、仅此一家、史无前例、
绝无仅有、前无古人、万能、100%、百分百、全球领先、国际领先、行业领先、领导品牌、
王牌、冠军、之王、之最、极致、顶级、终极、完美、绝对、永久、永不、最、首个、首家、
首发(用于自我排名时)、最新技术、最先进、最便宜、最低价、史上最低、全网最低、
跌破底价、亏本甩卖、清仓价

### 2.2 虚假 / 夸大效果

彻底解决、根治、一次搞定、立竿见影、当天见效、七天速成、包过、包会、包瘦、
稳赚、躺赚、零风险、无风险、稳定收益、保本、日入过万、月入十万、轻松月入、
秒变、逆袭、暴涨、暴富、白捡、免费送(实际有条件时)

### 2.3 诱导与虚假紧迫

最后一天、仅剩 X 件(编的)、错过再无、马上抢、秒杀(与事实不符时)、
限时限量(与事实不符时)、点赞抽奖(平台另有规则)、关注才能看、不转不是中国人

### 2.4 医疗 / 身体功效(用在非药品非器械上)

抗癌、防癌、消炎、杀菌率 99%、修复受损、排毒、养肝护肾、壮阳、丰胸、
减肥不反弹、去疤、生发、美白祛斑(宣称功效时)

### 2.5 身份与权威背书(无实据时)

国家机关推荐、XX 部门认证、专家推荐、权威认证、国家免检、
中国驰名商标(用于广告宣传时)

## 三、平台口径(**类别,不是词表**)

> 小红书、抖音、视频号都**没有公开发布过逐词的违禁词清单**。平台侧真正能引用的只有
> 社区公约/规范里的**类别**。所以这一节只列类别,查词时**不做逐词判定**,
> 只提醒「这一段落在这个类别里,平台规则可能管,要自己再看一眼」。

- 导流到站外(留微信/QQ/手机号/私域二维码)
- 医疗美容、医疗器械、处方药相关内容的资质要求
- 金融、招商、加盟、投资类内容的资质要求
- 未成年人相关
- 数据造假、刷量、互赞互粉
- 抄袭搬运、未授权使用他人素材与音乐
- 商业推广未标注「广告 / 赞助 / 合作」

## 四、这份表**不做**的事

- **不联网更新**。词是死的,法条改了要人来改这个文件。
- **不登录任何平台**去查。零氪查词那类插件要频繁登录,这一条就是为了不那样做。
- **不替人拍板**。查词只给「命中哪一条 + 出处 + 替换建议」,改不改是他的事。
