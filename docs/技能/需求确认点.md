## 这条规矩是怎么来的

维护者 2026-09-23 13:05 的原话:

> 「不只是这张卡的问题,是如果后面这种自然语言需求的传递都会被曲解,那么用户的体验
> 会非常差,这里最好是能当场给一些确认的点,**不能假装自己搞懂了**。」

当天的例子:他在电话里说「把音色改成可配置、通话中能改」,一路传下来做成了
「念三个名字让他挑」;他的本意是「他模糊描述、或者她播一段样音,**她去库里挑**」。
中间**没有任何一处停下来问一句**,所以那一处曲解一直走到了实现。

## 什么时候用这一条

**每一次接到一句自然语言的需求或想法**,不管从哪个口进来:

- 需求卡在「梳理」态被推进;
- 选题卡在「构思」态被推进;
- 电话里他说「把 X 做了」「我想做一期讲 X 的」「帮我改一下 Y」;
- 他在随手记 / 对话里抛一个还没成形的想法。

**不用这一条的**:他答确认点本身、他点「通过 / 打回」、他问一件事(「做到哪了」)、
闲聊。那些不是"接需求",是接话。

**纯问答直接答,不列确认点 —— 哪个模式都一样,包括「先问我」**(2026-09-25,统筹在真壳里用「先问我」
问「我的规矩有哪些」,她答对了,却在后面又列了三条确认点)。「先问我」管的是**派活给别家、动他的文件**
之前先对一遍,不是每句话后面都挂一张确认单。判据:这一句办完,**有没有东西会被派出去、会被改**?
没有(问规矩、问进度、问某个文件在哪、问她是谁),就直接答完;答的时候发现他其实想让你去办一件事,
再按下面那一套问。

## 只在这四类事上问他(2026-10-04,维护者点头)

他的原话:「别拿细枝末节来问我拍板」「总抛些无关紧要的给我拍版,你和事务官一个毛病」。
运营同学 10-02 独立反馈的是同一个病:「频繁询问是否继续……每一步设置得太细了」。

上面那一节说的是**怎么问**(拿不准才问、一次只问最要紧的、不复述);
这一节说的是**问什么** —— 这四类是问他的**全集**:

1. **改他的使用习惯**(他平时怎么用、以后都照哪个样子来);
2. **要花钱,或者要用掉额度**;
3. **对外怎么说**(发布、发消息给别人、对外的口径);
4. **要他亲手做的事**(登录、付款、验证码、给凭据)。

**此外一律自己定、照做**:实现细节(用哪个办法、文件叫什么名、放在哪个目录)、
默认值(先按最可能的那个来)、要不要记一笔(记忆、交接、日志)这一类**不要问他**,
事后一句话告诉他定了什么。

为什么是这四类:它们的共同点是**答案只有他知道,或者代价只有他能承担** ——
改他的习惯只有他说得清、钱和额度是他的、对外的话收不回来、要他亲手做的事别人做不了。
剩下的答错了能改,所以不值一次打扰。

### 这一条与那三道门各管什么(都不冲突)

| 哪一样 | 管什么 | 谁按下那一下 |
|---|---|---|
| **这一条**(只问四类) | 我**主动开口问他**之前,先看这一问属不属于那四类 | 我自己 |
| **「先问我」档** | 这一件**要不要派给别家 / 动他的文件**时先对一句 | 他选的档 |
| **派活闸** | 派出去之前**界面上**那一下点头 | 他在卡上点 |
| **上限问话** | 钱撞线了停下来问「接着做 / 停掉这一件 / 换一家」 | 他答那一问 |

后三样是工作台替他设的闸(他自己开的档、界面上的一下、撞线停住),
这一条管的是**我嘴里那一问**。上限问话本来就落在「要花钱或额度」这一类里 ——
同一个判据的两种形式,不是两条规矩。

### 他规矩表里那条同义的,与这一条是同一条

他会在「他的规矩」那一节留一条同义的(「别拿细枝末节来问我」)。
那一条与这一节**是同一条,不是两条**:**照一条办** —— 不许为同一件事问两遍,
也不许在回话里把同一个意思念两遍。

## 我先说的那一段

**先问自己一句:我真的拿不准吗?** 拿得准就直接办,办完说结果 —— 这一条治的是
「假装搞懂了」,不是「每句话后面挂一张确认单」(2026-10-02 改,卡「电话里像个活人」:
Air 那几通里「要你确认三点 / 跟你核三条」出现 8 次,连「查个天气」也过了一遍,
她的原话是「念了一遍经书」)。

**在屏幕上**(需求卡、选题卡那一节)拿不准就列出来,一条一行、各带我的默认理解:

```
① <问他的那一句>(我先按「<我的默认理解>」理解)
② …
哪条不对说一下,都对就开工。
```

**在电话里**(或者任何用嘴说的地方)**只问一句**,而且是最要紧的那一件:

```
<问他的那一句>?我按「<我的默认理解>」办。
```

四条硬规矩:

1. **拿不准才问**。一句话里缺的那一块不影响做法,就按最可能的那个做,顺口说一句我按什么做的。
2. **一次只问最要紧的那一件**。一口气问八条和不问是同一种失败 —— 他会只答最后一条。
   屏幕上最多列到四条;**嘴里只说一条**。
3. **每条都带我的默认理解**。只问不答等于把活推回给他;带上默认之后他可以只说
   「第二条不对」,别的就算数。默认理解必须是一个**真能照着做**的说法,不是「待定」。
4. **不复述**。他刚说完,他知道自己说了什么 —— 「我理解的是……」那一句删了
   (2026-10-02)。验收那一条(「怎么算做完」)仍然必须落到卡上,它是子事项验收标准的来源;
   只是**不必每次念给他听**。

## 确认点从哪儿来(规则,不是我临场想)

先看他这句需求**像哪一类**,再从那一类里挑。同时像两类就两类各出一条。

| 像哪一类 | 问哪三件 |
|---|---|
| **交互**(点、按钮、界面、显示、选、配置、说、通话…) | 用户怎么触发 / 看到什么 / 说不清时怎么办 |
| **数据**(数据、统计、报表、同步、采集、多久、来源…) | 从哪来 / 多久一次 / 没数据时显示什么 |
| **动作**(派、发、删、改、执行、合并、部署、通知…) | 谁执行 / 失败怎么办 / 要不要二次确认 |
| 三类都不像 | 归谁办、动的是哪一处 / 这一版做到哪儿为止 |

外加必有的那一条:**怎么算做完**。

**我不自己拼这张表**:工作台有一条现成的路,回来的就是按上面这张表挑好的几条 ——

```
POST {{工作台地址}}/confirm/points { "text": "<他那句需求>" }
→ { ok, need, points: [{ ask, guess }...], block, spoken }
```

`block` 是屏幕上那一段的成品,`spoken` 是电话里说的那**一句**(2026-10-02 起只有一条)。
**照着用,不要重写一版**:三处各写一份规则,"她问了哪几件"就再也说不清了。
这条路不通(旧版工作台 404 / 连不上)时,**至少问「怎么算做完」那一条**,并如实说
「我这会儿问不到那张表,先按我自己想的这几条问」。

## 他答完之后

- 他说「都对 / 开工」→ 按默认理解开工;
- 他逐条纠正 → **把他的原话写回那一条**,别的仍按默认;
- 他说「先记着」→ **只建卡,不派活**,卡上标「未确认」,下次再问。

然后**必须去点一下留痕那一下**(这一下才算"过了确认点"):

```
POST {{工作台地址}}/feature/confirm { "id": "<卡 id>", "points": [{ ask, guess, answer? }...] }   # 需求卡
POST {{工作台地址}}/topic/confirm   { "id": "<卡 id>", "name": "<选题名>", "points": [...] }      # 选题卡
```

工作台会做三件事,**我一件都不用自己做**:

1. 把「确认点」那一节写进 `需求.md` / `框架.md` 的**顶部**(已经有就原地换,段外不动);
2. 往这条卡的 `审核记录.jsonl` 追一行 `confirm_points`,含**他改了哪几条**;
3. 按确认点生成「验收标准」那一节 —— 一条确认点一行,他答过的用他那句,
   没答的写「(按默认)」。

回包里的 `acceptance` 就是那几行验收标准,**拆子事项时每件的验收标准从它来**。

## 没过确认点之前

**不派活、不动代码、不往下一态推。**

一次被曲解的需求派出去之后,几家 AI 做出来的全是错的那一版 —— 那比慢一轮贵得多。
工作台在「推进这一步」的那段话里会直接写着「这一步不要派活」,我照做。

电话里的分寸另有两条(它们不是可选的):

- **嘴里只说一条,一句说完**。电话里念三条就是「念了一遍经书」(2026-10-02 起从三条收成一条,与上面第 2 条同一个口径)。
- 他说「先记着」= 只记下不派,标「未确认」,**别说「我去办了」**(2026-10-02:也别说「我让事务官去办」—— 电话里的我就是事务官本人)。

## 不做的

- **不问复述废话**。「你是想做一个音色功能对吗」不是确认点 —— 确认点必须是
  **会影响做法的分歧点**。判据:他两种答法会让我做出两个不一样的东西,才算一条。
- **不把确认点当采访**。屏幕上最多四条、嘴里一条,问完就开工,不追着他问下一条。
- **不代他答**。他没答的那一条写「(还没答)」/「(按默认)」,**不写一个他没说过的答案**。
- **不在没过确认点的时候说「我懂了」「这就去办」**。那正是这条规矩要治的病。
- **不改他的原话**。问的那一句用他的词,纠正那一句逐字照抄。
