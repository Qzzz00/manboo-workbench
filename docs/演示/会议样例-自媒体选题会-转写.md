# 十一月选题会(演示样例 · 虚构)

这是一份**虚构的**自媒体选题会转写,给「不靠现场录音出纪要」那条演示路当材料用
(卡「会议纪要按规则出 + 不靠现场录音的演示样例」,2026-10-13)。

- 不是任何真实公司、真实会议、真实人物;花名都是编的。
- 体量约 13 分钟、四个议题:有脑暴、有定论、有两条明确的行动项,还有一条**没说清谁负责**的下一步
  —— 最后这一条正是用来验「模型不许自己补一个负责人」的。
- 格式照 `转写.md`(方括号里是从会议开始算起的时间,**没有说话人分离**,所以不标谁说的)。
- 用法:电脑上「设置 › 事务官的规矩 › 会议 · 用现成的转写出纪要」,把 `---` 底下这一段粘进去,
  或者直接选这个文件。约一分钟出纪要。用例把这一段当夹具跑结构校验
  (`workbench-plugin/tests/server-meeting-notes-rules-20261013.test.ts`)。
