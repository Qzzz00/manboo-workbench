# 自定义模块 · 接口(写给做模块的那个人 / 那个 Agent)

2026-09-21 起,工作台的窗位叠里可以多出几格「自定义模块」:一份网页,铺满窗位槽,
点标签就切过来 —— 和事务官那一档是同一种嵌法。

这一页说的是**做一个这样的模块要遵守什么**。用户那一侧怎么用,见
`docs/交接-0921-自定义模块容器.md`。

---

## 一、一个模块就是一个目录

(2026-10-21 起目录搬进用户层:`~/.dsh/workbench/用户层/网页小组件/`;老的 `~/.dsh/workbench/modules/` 起服务时整个搬过来。
接口与边界一条没变。见 `docs/设计-分层第一刀-2026-10-21.md`。)

```
~/.dsh/workbench/用户层/网页小组件/
  tool-a1b2c3/
    module.json      ← 必须有,没有它这个目录不算一个模块
    index.html       ← 入口。**单文件**,样式与脚本都写在里面
    assets/…         ← 可选。图片、额外的 css/js
  .trash/            ← 回收站(移除过的模块搬到这儿,一个字节都不删)
```

`module.json`:

```json
{
  "version": 1,
  "id": "tool-a1b2c3",
  "name": "番茄钟",
  "created_at": "2026-09-21T12:40:00+08:00",
  "source": "dsh",
  "entry": "index.html"
}
```

| 字段 | 说明 |
|---|---|
| `id` | **必须等于目录名**,只许 `[a-z0-9][a-z0-9-]{0,39}`(小写字母数字连字符,首字符不是连字符) |
| `name` | 窗位叠标签上那几个字,**最多 12 个字**(那一排是横着排的)。缺了就退回用 id 当名字 |
| `icon` | 可选,一个字符(比如一个 emoji),画在名字左边 |
| `created_at` | ISO 时间。清单按它升序排 —— **先做的在左边** |
| `source` | `dsh`(事务官交给 DSH 做的)/ `user`(用户自己放进去的)。缺省算 `dsh` |
| `entry` | 恒为 `index.html`。留这个字段是为了以后能换,不是为了现在能换 |

`module.json` 读不出来、不是合法 JSON、id 不合法 —— 这个目录**整个不进清单**。
不会报错,也不会猜:界面上就是没有这一格。

**装好不用重启工作台**:工作台每秒读一次这个目录,下一拍标签就出现了。

## 二、页面要长什么样

- **铺满整个窗口**:`html, body { margin: 0; height: 100% }`。它被嵌在窗位槽那块矩形里,
  那块矩形的大小会随布局变(用户拖过分栏把手、切过模板)。别写死宽高。
- **深色**:工作台是深色的,背景用 `#0b0d10` 这一档。
- **单文件**:样式与脚本写在 `index.html` 里。要拆也行(同目录下的 css/js),但别拆太碎 ——
  一个小工具的全部内容读一眼就该看完。

### 不许引外网

CDN、外网字体、图床,一个都不行。这**不是一句请求**:工作台给模块页面下了 CSP

```
default-src http://127.0.0.1:8794; script-src http://127.0.0.1:8794 'unsafe-inline';
style-src http://127.0.0.1:8794 'unsafe-inline'; img-src http://127.0.0.1:8794 data: blob:;
font-src http://127.0.0.1:8794 data:; connect-src http://127.0.0.1:8794 http://127.0.0.1:8791;
media-src http://127.0.0.1:8794 data: blob:; object-src 'none'; base-uri 'none';
form-action 'none'; frame-ancestors http://127.0.0.1:* http://localhost:*
```

引了也加载不出来,浏览器控制台里会明写被 CSP 拦掉。`connect-src` 里只有两个地址
(模块自己的来源 + 工作台服务),**外网打不出去**。

> 为什么写的是实名地址而不是 `'self'`:那块 iframe 加了 `sandbox`,文档是**不透明来源**,
> 而不透明来源里的 `'self'` 谁都不匹配 —— 写 `'self'` 的话连模块自己的 `assets/app.css`
> 都会被拦掉。端口不是写死的(`WORKBENCH_MODULE_PORT` 能改),上面那份是默认值。

### 用不了 localStorage(2026-09-22 起)

`sandbox` 带来的另一头:**`localStorage` / `sessionStorage` / IndexedDB / cookie 一概用不了**,
碰它们会抛 `SecurityError`。所以:

- 只属于这一次的东西(计时进度、上次选的档位)放内存就行 —— 切走那一格不卸载,切回来还在;
- 要留得住的(跨重启、跨设备),落一条**随手记**或一件**事项**;
- 照着老规范写了 `localStorage` 的模块**不会崩**,只要像样例那样包一层 `try/catch`。

这不是遗憾,是想要的:模块之间因此天然不共享任何浏览器存储,一个模块读不到另一个模块存的东西。

### 能端出去的文件类型

`html css js mjs json txt svg png jpg jpeg gif webp ico woff2`。**白名单**,表外的一律不给
(请求会得到 400「这种文件不给」)。所以别指望往模块目录里放一个 `.sh` 或 `.wasm` 让页面去拉。

## 三、页面能用的接口

直接 fetch 相对路径(容器会把它改写到工作台服务上,见下面「令牌怎么拿」):

| | 干什么 |
|---|---|
| `GET /state` | 工作台此刻的整份快照 —— 事项、随手记、会话、额度、布局、窗位叠…… **读什么都从这里读** |
| `POST /task/create` `{title, desc?, status?}` | 建一件事项 |
| `POST /task/move` `{id, status}` | 挪一件事项(七态) |
| `POST /task/update` `{id, …}` | 改一件事项 |
| `POST /note/add` `{text}` | 往随手记里落一行(列表在 `/state.notes`) |
| `POST /note/remove` `{id}` | 删一行随手记 |
| `GET /module/data?name=<采集器名>` | **2026-09-23 加的第七条**:她的采集器采回来的那一页文字,`{ ok, name, at, text, last }`。`text` 是页面上看得见的字、原样;没采成过时 `text` 为空、`last` 里写为什么。只读、只认 `name` 一个参数、别的文件读不到。**把字变成数是模块自己的事**,读不懂就明说,不编数 |
| `POST /xhs/refresh` | **2026-10-01 加的第八条**(C2「小组件派出去」):现在去小红书后台取一次数(内置「数据复盘」那颗「刷新」打的就是它)。**受它原有的频率闸**:两次之间至少 10 分钟,没到就原样回上一次的结果 —— 别写重试循环。取回来的数在 `/state.xhs` 里 |
| `POST /files/asset-reveal` `{name}` | **2026-10-01 加的第九条**:在 Finder 里打开**一个素材文件夹**。只收**文件夹名**(`{"name":"脚本"}`),路径由工作台自己查;名字从 `/state.template.asset_dirs`(名字 → 绝对路径)里读,不在那一份里回 404 |

**就这九条。别的一条都打不通** —— 不是"请不要碰",是打过去会收到 403
(`自定义模块用不了这条接口`)。`/files/reveal`、`/files/rect`、`/files/pin`、`/slot/*`、
`/dock/*`、`/layout`、`/credentials`、`/pair/*`、`/hooks`、`/modules/*` 全在这一句里。

> **任意路径的 `POST /files/reveal` 不在表上**(2026-09-22 拿掉的):它收任意路径,还会在这台
> Mac 上弹出一个 Finder 窗口,而模块本来也看不见文件路径 —— 那条口子给的不是模块要用的能力。
> 2026-10-01 换成了上面那条 `POST /files/asset-reveal`:**只收素材文件夹名,路径由服务端解析**,
> 能打开的集合就是模板建出来的那几个文件夹,有限、她自己看得见。工作台自己的页面
> (图谱、素材那一排、随手记文件卡)照旧用 `/files/reveal`,走的是另一道门。

> 这两条是为「**她自己那一版的内置格**」开的(技能《改造内置小组件》):她把内置「数据复盘」
> /「素材管理」收起、换成自己那一版之后,刷新与点开文件夹这两件事不该跟着没了。

### 令牌怎么拿(2026-09-22)

容器会往页面的文档头上注入一段前言,给你三样东西:

| | |
|---|---|
| `window.WB_API_BASE` | 工作台服务的地址(默认 `http://127.0.0.1:8791`) |
| `window.WB_MODULE_TOKEN` | **这个模块专用**的短期令牌(30 分钟,过期自动续,读它总是拿到当下有效的那把) |
| `window.WB_MODULE_API` | 上面那九条路径,摊平成一个数组 |

前言还包了一层 `fetch`:**你照上表写相对路径就行**(`fetch('/state')`),它会自动改写成
`WB_API_BASE + 路径` 并带上 `Authorization: Bearer <令牌>`,401 时自己去续一把再重试一次。
要自己发请求(`XMLHttpRequest`、`EventSource`、`navigator.sendBeacon`)就手动拼:

```js
await fetch(WB_API_BASE + '/note/add', {
  method: 'POST',
  headers: { 'content-type': 'application/json', authorization: 'Bearer ' + WB_MODULE_TOKEN },
  body: JSON.stringify({ text: '一行' }),
})
```

令牌**只属于这一个模块**,而且随时可以被吊销(把模块移进回收站就是一次吊销)。
**别把它写进文件、别往外发** —— 它每次打开页面都是新的,存下来没有意义。

### 不给凭据、不给 shell

- 页面里**不许出现任何 API Key、密码、Cookie**。要用模型就去建一件事项,让事务官去办。
  (模块令牌是个例外,而且它是容器注入的 —— 你不用、也不该把它写进文件。)
- **没有执行命令的接口**,也不会有。
- 只属于这个小工具自己的东西放内存(见上面「用不了 localStorage」)。

### 边界在哪儿(2026-09-22 改了,这一段是新的)

**这张表现在是一道真门了。** 之前不是 —— 之前模块页面与工作台同源,表只是一份规范。
维护者 2026-09-21 拍板(决策记录 C7)之后改成:

| 这道门 | 拦住什么 |
|---|---|
| **单开来源**。模块页面由另一台监听端出来(默认 `127.0.0.1:8794`,只绑回环),工作台服务是 `8791` | 模块打工作台任何一条接口都是**跨源**,浏览器一定带 `Origin`,页面里改不掉 |
| **iframe `sandbox="allow-scripts allow-forms"`**(故意不给 `allow-same-origin`) | 文档成了不透明来源:读不到工作台页面的任何东西,也没有浏览器存储可用 |
| **白名单**。工作台服务看见模块身份就当场降权,只放行上面那九条 | `/credentials`、`/pair/start`、`/layout`、`/dock/*`、`/files/reveal`、别的模块的 `/modules/<id>/remove` —— 一律 403,**一个字都不办** |
| **模块令牌**。一个模块一把,30 分钟,可吊销 | 没令牌连 `/state` 都读不到(401);模块移进回收站,它手里那把当场作废 |
| **不发 `Access-Control-Allow-Credentials`** | 模块带不了工作台的账号 cookie |
| **CSP + 文件类型白名单**(老的那两条,还在) | 外网脚本加载不了、fetch 出不去;`.sh`/`.wasm` 端不出来 |

拦不住的也写在这儿,别当它是铁桶:

- 本机上**别的进程**照样能直接打 8794 把模块页面拉下来 —— 8794 只绑回环,而回环在这台
  机器上本来就是全权信任的。这一版没有把"本机进程之间"也当成边界。
- 模块能打的九条里**有一条会在屏幕上弹出东西**:`POST /files/asset-reveal`(2026-10-01 加的)。
  它弹出来的是她刚点的那个素材文件夹 —— 与她在内置「素材管理」那一格里点一下的结果一模一样,
  而且能打开的集合只有模板建出来的那几个文件夹(名字由服务端解析成路径)。任意路径那条照旧不在表上。
- 它们照样能改看板与随手记:一个写岔了的模块可以建一串事项、删掉随手记 ——
  拦这个的是"一个模块从需求到落盘要过他亲手点的那一下确认",不是这张表。

人那道门还在,而且没变:一个模块从需求到落盘,中间必须过用户亲手点的那一下确认
(见下一节)。**不要绕过它往 `modules/` 里写东西。**

## 四、从一句话到一格标签(事务官那条链路)

1. 用户点窗位叠上那颗「**开发一个小工具**」,输入框里预填
   「我想在窗口槽这个位置开发一个工具类的小应用,它要做的是:」,他接着说想要什么。
2. 工作台**认出**这是一次造模块的请求(以那句话开头,或者 body 里写了 `kind: 'dev_tool'`),
   **什么都不做** —— 不建事项、不开会话、不写一个字节。先摆一条:
   「我把它记成了这件事,对吗?」+ 复述(**是从他原话里切出来的,一个字都不是生成的**)
   + 「给它起个名」。
3. 他点「就这样,交给 DSH」→ `POST /devtool/confirm {id, name}` → 这一刻才建一件事项、
   开一条 DSH 会话,把**产出规范**(就是这一页的机器版)作为第一条消息发出去。
4. DSH 照着规范把东西写进 `modules/<id>/`。
5. 窗位叠那一排最右边多出一个标签。事务官说一句「做好了,标签在窗位叠最右,叫 X」。

如果你是那个 DSH:**你收到的那条事项里自带全部规范**,不需要先读这一页。
这一页是给人读的,那条消息是给你执行的,两边说的是同一件事。

## 五、路由一览(服务端)

**工作台服务(8791)** —— 这几条是给**工作台界面**用的,模块自己一条都打不动:

| | 门 | |
|---|---|---|
| `GET /modules` | 本机 / 已配对设备 | 清单:在用的 + 回收站里的 |
| `POST /modules/<id>/remove` | 同上 | 移进 `.trash/`(**不删**),顺手吊销这个模块的令牌 |
| `POST /modules/<id>/restore` | 同上 | 从回收站拿回来 |
| `POST /devtool/confirm` | 同上 | `{id, name}`,确认之后才交给 DSH |
| `POST /devtool/cancel` | 同上 | `{id}`,这条需求就地作废 |

`GET /modules/<id>/<路径>` **在 8791 上已经没有了**(2026-09-22)。留一条同源的备用路
等于给刚立起来的边界开一个后门。打过去只会收到一句
`模块文件不在这台服务上了:它有自己的来源`。

**模块来源(8794,只绑回环)** —— 这台**只**做两件事,没有任何工作台的东西:

| | |
|---|---|
| `GET /modules/<id>/<路径>?wb=<令牌>` | 模块的静态文件。**iframe 的 src 就是这条**。HTML 会被注入前言;子资源(css/js/图片)照端不注入 |
| `POST /__wb/renew` | 拿旧令牌换一把新的(前言自己调,模块作者不用管) |

那块 iframe 的 src **不由前端拼**:`/state.modules[].frame_url` 里是服务端签好的整条
(端口与令牌只有服务端知道)。这个字段缺席 = 单开来源没起来 = 这一格挂不出来 ——
界面不会退回同源那条老路。

路径穿越有三道:id 白名单正则 → 逐段检查(`..`、`.` 开头、反斜杠、NUL 一律否,**先解码再判**)
→ `realpath` 量一次(**指到目录外面的软链接只有这一道抓得住**)。

## 六、一份真样例

`docs/assets/自定义模块-样例-番茄钟/` —— 番茄钟,单文件,用了 `GET /state` 与 `POST /note/add`,
一个外网地址都没引。想照着做一个,从它开始抄比从这一页开始快。

它是 2026-09-21 写的,2026-09-22 单开来源之后**一个字都没改还是照跑** —— 那正是这次改动
想要的结果:老模块目录不用动,令牌与来源都由容器接管。
