# 下班例程(总管每天一次;维护者 说「下班」或到点触发)

> 2026-09-15 起由工作台代跑第 1、2、3、4、6、7 步(`POST /routine/run {name:'evening'}` 或 routines.json 里的时刻,默认 18:30),
> 再开一条 DSH 会话按 `.dsh/skills/例程/SKILL.md` 做第 5、8 步与矛盾/待拍板。交接见 docs/交接-0915-事务官日常例程.md。
> 2026-09-26 起**前面多一步第 0 步「收」、第 5 步多一件「并」、第 7 步的 push 由代码做**
> (设计 docs/设计-讨论结论都落进工作台记忆-2026-09-26.md);其余步骤本身不变。

目的:让第二天的总管不用问「工作台长什么样、你是谁、项目到哪了」。全程只读工作台状态与仓库,写入只限记忆目录与决策记录「待拍板」。

0. **收**(工作台做;2026-09-27 起**开工汇报时也收一次**,只收不并 —— 白天新记的东西不用等到第二天晚上):
   授权表 `read_client_files = 可以` 时,把各家 AI 自己记的东西拷进 `docs/记忆/来自-<家>/`
   (只读原件、只收 `.md`、软链不跟);再对着 `来自-<家>/已并入.md` 里记的内容指纹,算出**这次新增或变了的**那几份。
   授权不是「可以」就整步跳过,并在汇报里说一句现在是哪一档。清单出现在会话第一条消息里,给第 5 步用。
1. 读 `GET http://127.0.0.1:8791/state`:`layout`、`dock.stack`、`apps`、`scenes`、`projects`、`tasks`、`daily`。
2. 覆盖写 `docs/记忆/工作台-布局.md` 与 `.html`:**直接取工作台生成的那一份**——
   `curl -s http://127.0.0.1:8791/snapshot/layout.md`(html 同理换后缀),或者读当天归档
   `~/.dsh/workbench/snapshots/layout-<日期>.{md,html}`(工作台每天 18:30 落,留 14 天)。
   「每个模块里有什么」那一节量不出来,是人写的知识,保留手写、不被覆盖。
3. 对每个项目文件:按 `projects[]` 的 signals 与 `tasks` 更新「进展」(追加一条带日期)、「当前冲刺/任务」、「风险」(排期风险等级);改「一句话/阶段/目标」只能写进决策记录待拍板。
4. 更新 `项目/索引.md` 的「最近活动」列。**索引里有的项目都要有文件**:缺的由工作台按模板建一份「待梳理」的档,索引里不留空链接。
5. **并 + 偏好**(模型做):
   - 第 0 步那份清单里的每一份**逐份处理,处理完一份立刻记一行台账,别攒到最后**
     (2026-09-26 攒到最后那次会话断在第 23 份,台账一行没写、并好的文件没提交):
     先在目标文件里搜这份的原件路径 —— 已经作为依据出现过 = 以前并过了,只补台账那一行;
     没出现过才读它,属于他偏好习惯的并进 `用户-<称呼>.md`「观察」段,属于某个项目的并进
     `项目/<名>.md` 的「进展/风险/关键文件」,每条**带依据(原件路径)**;纯技术备忘不并,但也算已看过。
     每一份处理完(含不并的)立刻在那一家的 `来自-<家>/已并入.md` 里追加一行:
     `| 文件 | 指纹 | 日期 | 并到哪 |` —— 记了的下次就不再列;**每 5 份 commit 一次**。
     只处理清单里列出来的那几份。
   - 今天对话里听到的偏好/自述 → `用户-<称呼>.md`「观察」段追加(这个仓库里就是 `docs/记忆/用户-*.md` 那一份)。
6. 重写 `docs/记忆索引.md`(全仓库一行一文件,最后更新日期)。
7. 一次 commit:`chore(记忆): 下班例程 <日期>`。**推由代码做**:这个工作目录配了远端(当前分支有 upstream)
   工作台就 `git push`,没配就不推、汇报里说「只存在这台电脑」,推失败把原因写进汇报。
   模型自己那一笔(第 5 步写的)自己提交,配了远端也自己推一次。
8. 回 维护者 三行:今天记住了什么、有什么矛盾、有什么待拍板;第一行末尾带一句「今天从各家 AI 收了 N 份、并进 M 条」。

9. **收尾**(工作台做,2026-09-27 起;不算例程的一步,每 10 分钟 + 每条例程开跑前各一次):
   刷新每一家 `来自-<家>/来源.md` 顶上那一块「这一家到哪了」(最近一次收、并入进度、最近一次并入);
   记忆路径下有没提交的改动、且最近 10 分钟没人再动文件 → 一次 `chore(记忆): 收尾(接上次没写完的)`,
   配了远端就推。**会话中途断了也看得出并到哪、写的东西不会一直留在工作区**。

不做:不改 AGENTS.md、不改 docs/记忆/README.md、不删任何文件、不写凭据、不碰 ~/.dsh。
