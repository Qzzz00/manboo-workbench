## 五步与判据(每步证据:请求方法 / 路径 / 状态码、卡状态、派活账、时间;**不记正文与凭据**)

1. **派出**:桌面入口说「交给小K把 README 第一行改成『工作台验收』」→ 卡建好、负责人是
   小K名片、**真的派出去**(命令行那只手有 pid / 起止时刻 / 退出证据,不是只显示在做)。
2. **交回**:执行者结果落卡 → 卡到「等你确认」。
3. **退修给同一执行者**:事务官按卡上验收条件自己验收(第一次交回**故意缺日期行**)→
   带结论留言 + 挪回「在做」+ 把退修捎回执行者;续跑接**原会话**(`--session` 同一会话号,
   不另起作者),不把普通退修推给维护者。
4. **通过回写**:第二次交回达标 → 验收通过 → 卡完成;卡上回执 / 轮次 / 事务官会话留痕齐全。
5. **失败恢复**:派活通道注入断一次 → 卡如实挂阻塞(原因在账)→ 同事项 continue 把
   处置办法送进事务官会话 → 同一卡重派成功,不重复派、不另起作者。
