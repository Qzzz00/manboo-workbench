Tabler Icons v3.46.0 — 120 offline filled icons and 43 legacy outline icons
https://github.com/tabler/tabler-icons/tree/v3.46.0/icons/filled
https://github.com/tabler/tabler-icons/tree/v3.46.0/icons/outline
Official source license: https://raw.githubusercontent.com/tabler/tabler-icons/v3.46.0/LICENSE
Catalog: assets/library-manifest.json lists 120 default icons and 43 legacyIcons,
including canonical id, original sourceId, style, source URL and SHA256 hash.
The 163 files under assets/library/ are unmodified official SVGs. Chinese labels,
categories and search tags are local catalog metadata. icon-library.js embeds
these same source SVGs for offline use without runtime downloads. Only filled
icons appear in listBuiltinIcons; legacy outlines remain accessible by exact id.
Five canonical ids use semantically equivalent official filled sources:
phone-off -> phone-x; checkbox -> square-check; upload -> file-upload;
coffee -> mug; plant -> seedling. Original SVG bytes remain unchanged.
Existing mood-smile, mood-wink and phone scene assets outside assets/library/
retain their outline source and existing attribution. Scene adaptation in
icons.js omits facial outer circles and samples strokes into 3D targets;
this does not modify the catalog source files.
